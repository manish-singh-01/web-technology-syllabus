SMTP

SMTP stands for Simple Mail Transfer Protocol. It is an application-layer protocol used to send email messages between clients and mail servers and between mail servers.

01 • INTRODUCTION

What is SMTP?

SMTP is a communication protocol used for sending outgoing emails. When a user sends an email, the email application submits it to a mail server, which can forward it towards the recipient's mail server.

SMTP is primarily used for sending messages. Protocols such as POP3 and IMAP are commonly used to retrieve or access received emails.

02 • WORKING

How SMTP Works

Sender→ SMTP Server→ Recipient Mail Server
  • The sender writes an email and clicks Send.
  • The email application submits the message to an outgoing mail server.
  • The sending server locates the recipient's mail server, often using DNS MX records.
  • SMTP transfers the message to the recipient's mail server.
  • The recipient accesses the email using a mail application or webmail.

03 • PORT NUMBERS

Common SMTP Ports

  • Port 25: Commonly used for SMTP relay between mail servers.
  • Port 587: Commonly used for email submission with STARTTLS support.
  • Port 465: Commonly used for email submission with implicit TLS.

04 • COMMANDS

Common SMTP Commands

  • EHLO: Identifies the client and requests server capabilities.
  • MAIL FROM: Specifies the envelope sender.
  • RCPT TO: Specifies a recipient.
  • DATA: Begins the message content transfer.
  • QUIT: Ends the SMTP session.

05 • ADVANTAGES AND LIMITATIONS

Advantages of SMTP

  • Provides a standard method for sending emails.
  • Supports communication between different mail systems.
  • Can relay messages through multiple mail servers.

Limitations of SMTP

  • SMTP alone is not used to retrieve received emails.
  • Secure transmission requires appropriate TLS configuration.
  • Email delivery may fail because of invalid addresses or server problems.

06 • EXAM PREPARATION

Important Questions with Answers

1. What is SMTP?

SMTP stands for Simple Mail Transfer Protocol. It is an application-layer protocol used to send emails from clients to mail servers and between mail servers.

2. Is SMTP used to receive emails?

SMTP is primarily used to send email. POP3 and IMAP are commonly used by email clients to retrieve or access received messages.

3. Explain the working of SMTP.

The sender submits an email to an outgoing mail server. The sending server locates the recipient's mail server and transfers the message using SMTP. The recipient can then access the message.

4. Name three common SMTP ports.

Port 25 is commonly used for server relay, port 587 for message submission with STARTTLS, and port 465 for submission using implicit TLS.
