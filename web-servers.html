Web Servers

TOPIC 11

Introduction to Web Servers

Learn how web servers receive HTTP requests, process them, and deliver webpages and other resources to web browsers.

01 • INTRODUCTION

What is a Web Server?

A web server is software, and the computer running that software, that serves web content to clients using HTTP or HTTPS.

When a user opens a website, the browser sends a request to a web server. The server processes the request and returns a response containing the requested resource or an appropriate error.

Important Points

  • Web servers handle HTTP and HTTPS requests.
  • They deliver HTML, CSS, JavaScript, images, and other files.
  • They can serve static and dynamic content.
  • They may work with application servers and databases.
  • Examples include Apache HTTP Server, Nginx, and Microsoft IIS.

02 • PURPOSE

Why Do We Need Web Servers?

  • To make websites available to users over a network.
  • To receive and respond to browser requests.
  • To deliver website files and media.
  • To support dynamic web applications.
  • To manage connections, access rules, and request logging.

03 • WORKING

How Does a Web Server Work?

1. The user enters a website URL in the browser.

2. DNS helps the browser find the server's IP address.

3. The browser establishes a connection to the server.

4. The browser sends an HTTP or HTTPS request.

5. The web server processes the request.

6. The server returns an HTTP response.

7. The browser renders the received content.

Example

When you open a college website, the browser requests a page from its server. The server returns the required files, and the browser displays the webpage.

04 • TYPES OF CONTENT

Static vs Dynamic Content

Static Content

Static content is delivered as stored, without generating a new page for each request.

  • Examples: HTML files, CSS files, images.
  • The same resource can be served to many users.
  • Often simple and fast to deliver.

Dynamic Content

Dynamic content is generated or selected according to a request, user, or application data.

  • Examples: dashboards, account pages, search results.
  • May involve server-side code or databases.
  • Different users may receive different responses.

05 • WEB SERVER SOFTWARE

Types of Web Server Software

1. Apache HTTP Server

A widely used, open-source web server known for its modular architecture and flexibility.

2. Nginx

A web server that can also act as a reverse proxy and load balancer.

3. Microsoft IIS

Internet Information Services is Microsoft's web server software for Windows.

4. Node.js HTTP Server

A web server can also be built using Node.js and its HTTP APIs or frameworks such as Express.

06 • HTTP REQUEST AND RESPONSE

HTTP Request and Response

A browser sends an HTTP request, and the web server returns an HTTP response. 

GET /index.html HTTP/1.1
Host: example.com

HTTP/1.1 200 OK
Content-Type: text/html

<html>
  <body>
    <h1>Welcome!</h1>
  </body>
</html>

Explanation

  • GET: Requests a resource.
  • Host: Identifies the target hostname in this HTTP/1.1 request.
  • 200 OK: Indicates a successful request.
  • Content-Type: Describes the response body format.

07 • PORT NUMBERS

Common Web Server Ports

  • Port 80: Default port commonly used for HTTP.
  • Port 443: Default port commonly used for HTTPS.

HTTPS uses TLS to protect communication between the client and server.

08 • COMPARISON

Web Server vs Web Browser

Web Server

  • Receives requests and sends responses.
  • Hosts or serves website resources.
  • Examples: Apache, Nginx, IIS.

Web Browser

  • Sends requests to web servers.
  • Processes and displays web content.
  • Examples: Chrome, Firefox, Edge, Safari.

09 • ADVANTAGES

Advantages of Web Servers

  • Make website resources accessible over networks.
  • Can serve many client requests.
  • Support static and dynamic websites.
  • Provide logging and access-control features.
  • Can support secure HTTPS connections.
  • Can work with caching and load balancing to improve performance.
