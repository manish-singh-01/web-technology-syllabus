HTML Frames

Unit 2 | Topic 05

Learn how HTML frames and inline frames display multiple web documents.

1. Introduction to HTML Frames

HTML Frames were used to divide a browser window into multiple sections. Each section could display a separate HTML document.

Frames allowed different web pages to appear in the same browser window.

Important Points

  • Frames divide a browser window into sections.
  • Each frame can display a separate HTML document.
  • Frames were commonly used in older websites.
  • The traditional frame and frameset elements are obsolete in HTML5.

2. Types of Frames

A. Frame

The <frame> element was used to define an individual frame inside a frameset. It could load a separate HTML page.

Example

<frame src="home.html" name="mainFrame">

B. Frameset

The <frameset> element was used instead of the <body> element to define how the browser window should be divided into frames.

Example

<frameset cols="30%,70%">
    <frame src="menu.html">
    <frame src="content.html">
</frameset>

C. Inline Frame (iframe)

The <iframe> element is used to embed another HTML document or supported web content inside the current page. Unlike the old frame element, iframe is supported in HTML5.

Example

<iframe src="about.html"
        width="500"
        height="300"
        title="About Page">
</iframe>

3. Attributes of Frames

Some important attributes of the old frame element are:

  • src: Specifies the HTML document to display.
  • name: Assigns a name to the frame.
  • scrolling: Controls the scroll bar in older frame implementations.
  • noresize: Prevents resizing of a frame in older implementations.
  • frameborder: Controls the frame border in older implementations.

These attributes belong to the obsolete frame system and should not be used in modern HTML projects.

4. Attributes of iframe

Important attributes of the modern iframe element include:

  • src: Specifies the URL of the embedded document.
  • width: Sets the width of the iframe.
  • height: Sets the height of the iframe.
  • title: Provides an accessible description.
  • name: Assigns a name to the iframe.
  • loading: Controls loading behavior, such as lazy loading.
  • allow: Specifies permissions for supported features.
  • sandbox: Applies restrictions to embedded content.

Example

<iframe
    src="page.html"
    width="600"
    height="400"
    title="Embedded Page"
    loading="lazy">
</iframe>

5. Difference Between Frame and iframe

Frame iframe
Used with the frameset element. Used directly inside the body.
Divided the browser window into sections. Embeds content inside a page.
Obsolete in HTML5. Supported in HTML5.
Cannot be used as a modern HTML frame layout. Can embed another HTML document.

6. Practical Example of iframe

The following example displays another HTML document inside the current webpage. 

<!DOCTYPE html>
<html>
<head>
    <title>Iframe Example</title>
</head>
<body>

    <h2>My Website</h2>

    <p>Below is an embedded webpage:</p>

    <iframe
        src="about.html"
        width="500"
        height="300"
        title="About Us Page">
    </iframe>

</body>
</html>

7. Opening Links Inside an iframe

The name attribute can be used to target an iframe when a link is clicked. 

<iframe
    src="home.html"
    name="myFrame"
    title="Content Frame">
</iframe>

<a href="about.html" target="myFrame">
    Open About Page
</a>

8. Advantages of Frames

  • Allowed multiple documents to appear in one browser window.
  • Made it possible to keep navigation separate from content.
  • Individual frame content could be updated independently.
  • iframes allow external or separate content to be embedded in a page.

9. Disadvantages of Traditional Frames

  • Traditional frames are not supported in HTML5.
  • They can create navigation and usability problems.
  • Search engines may have difficulty understanding framed pages.
  • They can make responsive design difficult.
  • They may create accessibility problems.

10. Modern Alternatives to Frames

Modern websites generally use CSS and JavaScript instead of traditional frames to create page layouts.

  • CSS Flexbox: Creates flexible one-dimensional layouts.
  • CSS Grid: Creates rows and columns for page layouts.
  • iframe: Embeds another document when required.
  • JavaScript: Updates webpage content dynamically.

Quick Revision

  • <frame> – Defines an individual traditional frame.
  • <frameset> – Divides a browser window into frames.
  • <iframe> – Embeds another document in a webpage.
  • src – Specifies the document URL.
  • name – Assigns a name to a frame or iframe.
  • target – Specifies where a linked document opens.
  • Traditional frame and frameset elements are obsolete in HTML5.
  • iframe is supported in modern HTML.
