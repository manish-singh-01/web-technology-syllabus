AJAX – Improving Web Page Performance

Unit 3 – Web Services, AJAX and CORBA

1. Introduction to AJAX

AJAX stands for Asynchronous JavaScript and XML. It is a web development technique used to exchange data between a browser and a server without reloading the entire web page.

AJAX allows web applications to update specific parts of a page dynamically. It improves user experience by making websites more interactive and responsive.

Although XML is included in its name, AJAX can also exchange data in formats such as JSON, plain text and HTML.

2. Meaning of Asynchronous Communication

Asynchronous communication means that a browser can send a request to the server and continue performing other tasks while waiting for the server's response.

The entire web page does not need to reload when new data is received. JavaScript can update only the required part of the page.

3. Need for AJAX

AJAX is useful because traditional web applications often reload the entire page to display updated information.

  • To update web page content without a full page reload.
  • To improve the responsiveness of web applications.
  • To reduce unnecessary data transfer.
  • To provide a better user experience.
  • To load information in the background.
  • To make web applications more interactive.

4. Technologies Used in AJAX

1. HTML and CSS

HTML provides the structure of a web page, while CSS controls its design and appearance.

2. JavaScript

JavaScript handles user interactions, sends asynchronous requests and updates the page content.

3. DOM (Document Object Model)

DOM allows JavaScript to access and modify the elements of an HTML document dynamically.

4. XMLHttpRequest

XMLHttpRequest is a JavaScript object used to send HTTP requests and receive server responses asynchronously.

5. XML and JSON

XML and JSON are data formats that can be used to exchange information between the browser and server. JSON is commonly used in modern AJAX applications.

5. Working of AJAX

AJAX works by sending an asynchronous request from the browser to the server. The server processes the request and sends a response, which JavaScript uses to update the web page.

Steps of AJAX Working

  1. The user performs an action, such as clicking a button.
  2. JavaScript creates an asynchronous HTTP request.
  3. The browser sends the request to the server.
  4. The server processes the request.
  5. The server sends a response, such as JSON or XML data.
  6. JavaScript receives and processes the response.
  7. The DOM is updated without reloading the entire page.

Usually waits for a new page response. Can send requests asynchronously.

Less dynamic user interaction. Supports more dynamic interaction.
Example: Traditional form submission. Example: Live search suggestions.

7. Improving Web Page Performance Using AJAX

AJAX can improve the perceived performance of web pages by avoiding unnecessary full-page reloads and fetching only the data needed by the user.

  • Partial Page Updates: Updates only the required section of a page.
  • Background Requests: Fetches information without interrupting the user.
  • Reduced Data Transfer: Sends only the required data instead of a complete page.
  • Faster Interaction: Allows users to receive information without navigating to another page.
  • Better User Experience: Makes websites feel more responsive.
  • Efficient Data Loading: Loads information when it is needed.

Note: AJAX does not automatically make every application faster. Performance depends on server response time, network speed, request size and JavaScript processing.

8. XMLHttpRequest Object

XMLHttpRequest (XHR) is a built-in JavaScript object used to communicate with servers. It allows a web page to send HTTP requests and receive responses without a full reload.

Important Methods

  • open(): Initializes a request by specifying the HTTP method and URL.
  • send(): Sends the request to the server.
  • setRequestHeader(): Sets HTTP request headers.
  • abort(): Cancels an ongoing request.

Important Properties

  • readyState: Indicates the current state of the request.
  • status: Contains the HTTP response status code.
  • responseText: Contains the response as text.
  • responseXML: Contains the response as an XML document when applicable.
  • onreadystatechange: Handles changes in the request state.

9. AJAX Ready State Values

Value Meaning
0 UNSENT – Request object has been created.
1 OPENED – open() has been called.
2 HEADERS_RECEIVED – Response headers have been received.
3 LOADING – Response body is being received.
4 DONE – Request operation has completed.

10. Simple Example of AJAX

The following example uses XMLHttpRequest to load text from a server without reloading the complete web page. 

<!DOCTYPE html>
<html>
<head>
    <title>AJAX Example</title>
</head>
<body>

    <h2>AJAX Demonstration</h2>

    <button onclick="loadData()">
        Load Data
    </button>

    <div id="result"></div>

    <script>
        function loadData() {

            const xhr = new XMLHttpRequest();

            xhr.open("GET", "data.txt", true);

            xhr.onload = function() {
                if (xhr.status === 200) {
                    document.getElementById("result")
                        .innerHTML = xhr.responseText;
                } else {
                    document.getElementById("result")
                        .textContent = "Unable to load data.";
                }
            };

            xhr.onerror = function() {
                document.getElementById("result")
                    .textContent = "Network error occurred.";
            };

            xhr.send();
        }
    </script>

</body>
</html>

When the user clicks the button, the browser requests data.txt from the server. The received content is displayed inside the result div without reloading the page.

11. AJAX Using Fetch API

Modern JavaScript commonly uses the Fetch API to make asynchronous HTTP requests. It provides a Promise-based approach to handling responses. 

<button onclick="loadUser()">
    Load User
</button>

<div id="output"></div>

<script>
async function loadUser() {

    try {
        const response = await fetch(
            "https://jsonplaceholder.typicode.com/users/1"
        );

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const user = await response.json();

        document.getElementById("output").textContent =
            user.name + " - " + user.email;

    } catch (error) {
        document.getElementById("output").textContent =
            "Error loading user data.";
    }
}
</script>

In this example, Fetch API requests user information from a server. The response is converted into JSON and displayed on the page.

12. Advantages of AJAX

  • Updates page content without full-page reloads.
  • Improves perceived responsiveness.
  • Reduces unnecessary data transfer in suitable applications.
  • Supports asynchronous communication.
  • Makes web applications more interactive.
  • Works with different data formats such as JSON and XML.

13. Disadvantages of AJAX

  • Requires JavaScript to be enabled for client-side functionality.
  • Complex AJAX applications can be difficult to debug.
  • Incorrect handling of browser history can affect navigation.
  • Cross-origin requests may require proper CORS configuration.
  • Search engines may need additional support to process dynamically loaded content.
  • Security risks can occur if input and server responses are not handled safely.

14. Applications of AJAX

  • Live Search: Displays suggestions while users type.
  • Online Shopping: Updates shopping cart information.
  • Social Media: Loads new posts and notifications.
  • Email Applications: Updates inbox content dynamically.
  • Maps: Loads location information without refreshing the entire page.
  • Online Forms: Validates user input asynchronously.
  • Dashboards: Refreshes charts and statistics.

Important Points for Exams

  • It allows data exchange without reloading the complete page.
  • JavaScript handles AJAX requests and responses.
  • XMLHttpRequest is a traditional AJAX communication object.
  • Fetch API is a modern approach for asynchronous requests.
  • JSON is commonly used for data exchange.
  • DOM is used to update page content dynamically.
  • AJAX can improve perceived performance and user experience.
