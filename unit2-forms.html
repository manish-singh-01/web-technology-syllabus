HTML Forms

Unit 2 | Topic 04

Learn how to collect user information using HTML forms and form elements.

1. Introduction to HTML Forms

HTML Forms are used to collect information from users. They allow users to enter data such as name, email, password, phone number and other details.

Forms are commonly used in login pages, registration pages, contact forms, feedback forms and online surveys.

Important Points

  • Forms collect user input.
  • The form element is represented by the <form> tag.
  • Forms contain input fields and buttons.
  • Form data can be sent to a server for processing.

2. The HTML Form Element

The <form> tag defines an HTML form. It acts as a container for different form controls.

Syntax

<form action="submit.php" method="post">
    Form elements go here
</form>

Important Form Attributes

  • action: Specifies where the form data is sent.
  • method: Specifies how the data is submitted.
  • target: Specifies where to display the response.
  • autocomplete: Controls automatic form completion.
  • enctype: Specifies how form data is encoded.

3. GET and POST Methods

HTML forms mainly use two methods to send data: GET and POST.

GET Method

  • Form data is appended to the URL.
  • Data can be visible in the browser address bar.
  • It is useful for search forms and retrieving information.
  • It is not suitable for sensitive information.

POST Method

  • Form data is sent in the request body.
  • Data is not displayed in the URL.
  • It is commonly used for registration and login forms.
  • HTTPS is still required to protect sensitive information.

Difference Between GET and POST

GET POST
Data is sent through the URL. Data is sent in the request body.
Suitable for retrieving data. Suitable for submitting data.
Can be bookmarked with query parameters. Form submission is generally not bookmarked.
Not suitable for sensitive data. Better suited for sensitive data when used with HTTPS.

4. HTML Input Types

The <input> tag is used to create different types of input fields in an HTML form.

  • text: Accepts single-line text.
  • password: Accepts a password.
  • email: Accepts an email address.
  • number: Accepts numeric values.
  • radio: Allows selection of one option from a group.
  • checkbox: Allows selection of multiple options.
  • date: Allows selection of a date.
  • file: Allows file uploads.
  • submit: Submits the form.
  • reset: Resets form fields.
  • tel: Accepts telephone numbers.
  • url: Accepts a URL.
  • hidden: Stores data that is not displayed as a visible field.

Example

<input type="text" name="username">
<input type="password" name="password">
<input type="email" name="email">
<input type="number" name="age">
<input type="date" name="dob">

5. Important Input Attributes

  • name: Identifies the field when form data is submitted.
  • value: Sets the input's initial or submitted value.
  • placeholder: Displays a hint inside the field.
  • required: Makes the field compulsory.
  • readonly: Prevents the user from editing the field.
  • disabled: Disables the input field.
  • maxlength: Sets the maximum number of characters.
  • min and max: Set minimum and maximum values.

Example

<input type="text"
       name="username"
       placeholder="Enter your name"
       required
       maxlength="30">

6. Label Element

The <label> tag defines a label for an input field. It improves usability and accessibility. 

<label for="email">Email:</label>
<input type="email" id="email" name="email">

7. Select and Option Elements

The <select> element creates a drop-down list. The <option> element defines its choices.

Example

<label for="course">Choose Course:</label>

<select id="course" name="course">
    <option value="cse">Computer Science</option>
    <option value="it">Information Technology</option>
    <option value="ece">Electronics</option>
</select>

8. Textarea Element

The <textarea> tag creates a multi-line text field. It is useful for comments, messages and feedback. 

<textarea name="message"
          rows="5"
          cols="30"
          placeholder="Enter your message">
</textarea>

9. Button Element

The <button> tag creates a clickable button. It can be used to submit, reset or perform other actions. 

<button type="submit">Submit</button>
<button type="reset">Reset</button>
<button type="button">Click Me</button>

10. Fieldset and Legend

The <fieldset> tag groups related form elements. The <legend> tag provides a title for that group. 

<fieldset>
    <legend>Personal Details</legend>

    <label for="name">Name:</label>
    <input type="text" id="name" name="name">
</fieldset>

11. HTML Form Validation

Form validation checks whether the information entered by a user meets specified conditions.

Common Validation Attributes

  • required: Makes an input compulsory.
  • minlength: Sets the minimum text length.
  • maxlength: Sets the maximum text length.
  • min: Sets the minimum numeric value.
  • max: Sets the maximum numeric value.
  • pattern: Defines a pattern for input validation.

Example

<input type="email" required>

<input type="password"
       minlength="8"
       required>

<input type="number"
       min="1"
       max="100">

HTML validation provides basic client-side checks. Important information must also be validated on the server.

12. Practical Example: Student Registration Form

The following example demonstrates how different HTML form elements work together. 

<!DOCTYPE html>
<html>
<head>
    <title>Student Registration</title>
</head>
<body>

<h2>Student Registration Form</h2>

<form action="#" method="post">

    <label for="name">Full Name:</label>
    <input type="text" id="name"
           name="name" required>
    <br><br>

    <label for="email">Email:</label>
    <input type="email" id="email"
           name="email" required>
    <br><br>

    <label for="password">Password:</label>
    <input type="password" id="password"
           name="password" required>
    <br><br>

    Gender:
    <input type="radio" name="gender" value="male"> Male
    <input type="radio" name="gender" value="female"> Female
    <br><br>

    Skills:
    <input type="checkbox" name="skill" value="html"> HTML
    <input type="checkbox" name="skill" value="css"> CSS
    <br><br>

    <label for="course">Course:</label>
    <select id="course" name="course">
        <option value="cse">CSE</option>
        <option value="it">IT</option>
    </select>
    <br><br>

    <label for="message">Address:</label>
    <textarea id="message" name="address"></textarea>
    <br><br>

    <button type="submit">Register</button>
    <button type="reset">Clear</button>

</form>

</body>
</html>

13. Advantages of HTML Forms

  • Easy collection of user information.
  • Useful for login and registration systems.
  • Supports different input types.
  • Provides basic built-in validation.
  • Can be connected to backend technologies.
