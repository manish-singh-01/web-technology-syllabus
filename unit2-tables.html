TOPIC 02

Tables in HTML

Learn to organize data into rows and columns using HTML tables, headings, captions, colspan, and rowspan.

01 • INTRODUCTION

What is an HTML Table?

An HTML table is used to display structured data in rows and columns. Tables are useful for showing student marks, timetables, product details, and other tabular information.

Important Table Tags

  • <table> — Creates a table.
  • <tr> — Creates a table row.
  • <th> — Creates a header cell.
  • <td> — Creates a data cell.
  • <caption> — Adds a table caption.
  • <thead> — Groups header rows.
  • <tbody> — Groups the main data rows.
  • <tfoot> — Groups footer rows.

02 • BASIC TABLE

Creating a Simple Table

<table border="1">
    <tr>
        <th>Name</th>
        <th>Course</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Aman</td>
        <td>B.Tech</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Riya</td>
        <td>B.Tech</td>
        <td>90</td>
    </tr>
</table>

Expected Output

Name Course Marks
Aman B.Tech 85
Riya B.Tech 90

Note: The border attribute is shown for a basic learning example. CSS is the recommended way to style modern HTML tables.

03 • TABLE STRUCTURE

Rows, Columns, Headers and Cells

  • Row: A horizontal group of cells.
  • Column: A vertical group of cells.
  • Header cell: A heading, normally created with <th>.
  • Data cell: A regular cell, created with <td>.
<table>
    <caption>Student Records</caption>
    <thead>
        <tr>
            <th scope="col">Roll No.</th>
            <th scope="col">Name</th>
        </tr>
    </thead>

    <tbody>
        <tr>
            <td>101</td>
            <td>Aman</td>
        </tr>
    </tbody>
</table>

04 • COLSPAN

What is Colspan?

The colspan attribute allows one table cell to span across multiple columns. 

<table border="1">
    <tr>
        <th colspan="2">Student Details</th>
    </tr>

    <tr>
        <td>Aman</td>
        <td>B.Tech</td>
    </tr>
</table>

Remember

colspan="2" makes a cell span two columns.

05 • ROWSPAN

What is Rowspan?

The rowspan attribute allows one table cell to span across multiple rows. 

<table border="1">
    <tr>
        <th>Department</th>
        <th>Student</th>
    </tr>

    <tr>
        <td rowspan="2">CSE</td>
        <td>Aman</td>
    </tr>

    <tr>
        <td>Riya</td>
    </tr>
</table>

Remember

rowspan="2" makes a cell span two rows.

06 • CSS STYLING

Styling Tables with CSS

CSS controls table borders, spacing, text alignment, and background colors. 

table {
    width: 100%;
    border-collapse: collapse;
}

th, td {
    border: 1px solid #888;
    padding: 10px;
    text-align: left;
}

th {
    background-color: #eeeeee;
}
  • border-collapse combines adjacent borders.
  • padding adds space inside cells.
  • text-align controls horizontal alignment.
  • width controls the table's width.
