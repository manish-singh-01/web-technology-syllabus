TOPIC 01

Lists in HTML

Learn how to organize information using ordered, unordered, description, and nested lists in HTML.

01 • INTRODUCTION

What is an HTML List?

An HTML list is used to display a collection of related items in an organized format. Lists make webpage content easier to read and understand.

Types of HTML Lists

  • Ordered List — uses numbers or letters.
  • Unordered List — uses bullets.
  • Description List — displays terms and their descriptions.
  • Nested List — places one list inside another list item.

02 • ORDERED LIST

Ordered List (ol)

An ordered list displays items in a particular sequence, usually using numbers or letters. It uses the <ol> tag, with each item inside an <li> tag. 

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Output

  1. HTML
  2. CSS
  3. JavaScript

Ordered List Types

<ol type="1">...</ol>
<ol type="A">...</ol>
<ol type="a">...</ol>
<ol type="I">...</ol>
<ol type="i">...</ol>
  • 1 — Numbers: 1, 2, 3
  • A — Uppercase letters: A, B, C
  • a — Lowercase letters: a, b, c
  • I — Uppercase Roman numerals: I, II, III
  • i — Lowercase Roman numerals: i, ii, iii

The start attribute can specify the starting number of an ordered list. 

<ol start="5">
    <li>First displayed item</li>
    <li>Second displayed item</li>
</ol>

03 • UNORDERED LIST

Unordered List (ul)

An unordered list displays items with bullet markers instead of a numbered sequence. It uses the <ul> tag and <li> elements. 

<ul>
    <li>C++</li>
    <li>Python</li>
    <li>Java</li>
</ul>

Output

  • C++
  • Python
  • Java

CSS can customize bullet appearance using the list-style-type property. 

ul {
    list-style-type: square;
}

/* Other values:
   disc
   circle
   none
*/

04 • DESCRIPTION LIST

Description List (dl)

A description list displays terms and their descriptions. It uses three tags:

  • <dl> — Defines the list.
  • <dt> — Defines a term.
  • <dd> — Provides the description.
<dl>
    <dt>HTML</dt>
    <dd>Defines webpage structure.</dd>

    <dt>CSS</dt>
    <dd>Controls webpage presentation.</dd>
</dl>

Output

HTML
Defines webpage structure.
CSS
Controls webpage presentation.

05 • NESTED LIST

Nested Lists

A nested list is a list placed inside a list item of another list. It helps organize categories and subcategories. 

<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>Backend</li>
</ul>

Output

  • Frontend
    • HTML
    • CSS
    • JavaScript
  • Backend

06 • ATTRIBUTES

Important List Attributes

type

Specifies the marker style for an ordered list.

<ol type="A">

start

Sets the starting value for an ordered list.

<ol start="3">

reversed

Displays an ordered list in descending order.

<ol reversed>

list-style-type

CSS property used to customize list markers.

list-style-type: circle;

07 • PRACTICAL EXAMPLE

Student Skills List

The following example combines an ordered list with a nested unordered list. 

<h2>My Learning Plan</h2>

<ol>
    <li>Programming
        <ul>
            <li>C++</li>
            <li>Java</li>
        </ul>
    </li>
    <li>Web Development</li>
    <li>Database Management</li>
</ol>
