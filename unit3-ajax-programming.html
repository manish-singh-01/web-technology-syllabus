Programming in AJAX

Unit 3 – Web Services, AJAX and CORBA

1. Introduction to AJAX Programming

AJAX programming is the process of using JavaScript to communicate asynchronously with a web server and update web page content without reloading the complete page.

It allows developers to create interactive and dynamic web applications. AJAX can exchange data in formats such as JSON, XML, HTML and plain text.

2. Requirements for AJAX Programming

  • HTML: Creates the structure of the web page.
  • CSS: Provides styling and layout.
  • JavaScript: Handles user interaction and asynchronous requests.
  • DOM: Allows JavaScript to update page elements.
  • XMLHttpRequest or Fetch API: Sends requests to the server.
  • Server: Processes requests and returns data.

3. Steps in AJAX Programming

  1. Create an HTML page with the required elements.
  2. Write a JavaScript function to handle the request.
  3. Create an XMLHttpRequest object or use the Fetch API.
  4. Specify the HTTP method and server URL.
  5. Send the request to the server.
  6. Receive and process the server response.
  7. Update the required part of the web page using the DOM.

4. AJAX Programming Using XMLHttpRequest

XMLHttpRequest is a built-in JavaScript object that allows a browser to send HTTP requests and receive server responses without reloading the entire page.

Important Methods

  • open(method, URL, async): Initializes a request.
  • send(): Sends the request.
  • setRequestHeader(): Sets request headers.
  • abort(): Cancels an ongoing request.

Example: Load Data Using AJAX

Create two files: index.html and data.txt in the same folder.

index.html

<!DOCTYPE html>
<html>
<head>
    <title>AJAX Example</title>
</head>
<body>

    <h2>Programming in AJAX</h2>

    <button onclick="loadData()">
        Load Data
    </button>

    <div id="result"></div>

    <script>
        function loadData() {

            const xhr = new XMLHttpRequest();

            xhr.open("GET", "data.txt", true);

            xhr.onload = function() {

                if (xhr.status === 200) {
                    document.getElementById("result")
                        .textContent = xhr.responseText;
                } else {
                    document.getElementById("result")
                        .textContent = "Unable to load data.";
                }
            };

            xhr.onerror = function() {
                document.getElementById("result")
                    .textContent = "Network error occurred.";
            };

            xhr.send();
        }
    </script>

</body>
</html>

data.txt

Welcome to AJAX Programming!
Data loaded successfully without reloading the page.

When the user clicks the button, an AJAX request is sent to the server to retrieve data.txt. The response is displayed inside the result element.

5. AJAX Programming Using Fetch API

Fetch API is a modern JavaScript feature used to make asynchronous HTTP requests. It uses Promises and supports cleaner request and response handling.

Example: Fetch Data from a Server

<!DOCTYPE html>
<html>
<body>

    <h2>Fetch API Example</h2>

    <button onclick="loadUser()">
        Get User
    </button>

    <div id="result"></div>

    <script>
        async function loadUser() {

            try {
                const response = await fetch(
                    "https://jsonplaceholder.typicode.com/users/1"
                );

                if (!response.ok) {
                    throw new Error("Request failed");
                }

                const user = await response.json();

                document.getElementById("result").textContent =
                    "Name: " + user.name +
                    " | Email: " + user.email;

            } catch (error) {
                document.getElementById("result").textContent =
                    "Unable to load user data.";
            }
        }
    </script>

</body>
</html>

In this example, Fetch API sends a request to a server, receives JSON data and displays the user's name and email.

6. AJAX GET Request

The GET method is used to retrieve information from a server. It is commonly used when a browser needs to fetch records, user details or other data. 

fetch("/api/students")
    .then(response => {
        if (!response.ok) {
            throw new Error("Request failed");
        }
        return response.json();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.log(error);
    });

7. AJAX POST Request

The POST method is used to send data to a server. It is commonly used for submitting forms, creating records and sending user information. 

const student = {
    name: "Rahul",
    course: "B.Tech",
    department: "CSE"
};

fetch("/api/students", {
    method: "POST",

    headers: {
        "Content-Type": "application/json"
    },

    body: JSON.stringify(student)
})
.then(response => {
    if (!response.ok) {
        throw new Error("Request failed");
    }
    return response.json();
})
.then(data => {
    console.log("Student saved:", data);
})
.catch(error => {
    console.log("Error:", error);
});

In this example, student information is converted into JSON and sent to the server using a POST request.

8. Handling JSON Data in AJAX

JSON stands for JavaScript Object Notation. It is a lightweight data format commonly used for exchanging information between a browser and server.

Example JSON Data

{
    "id": 101,
    "name": "Rahul",
    "course": "B.Tech",
    "department": "CSE"
}

Converting JSON into JavaScript Object

const jsonData = '{"name":"Rahul","course":"B.Tech"}';

const student = JSON.parse(jsonData);

console.log(student.name);
console.log(student.course);

JSON.parse() converts a JSON string into a JavaScript object. JSON.stringify() converts a JavaScript object into a JSON string.

9. Handling AJAX Errors

Error handling is important because requests may fail due to network problems, server errors or invalid responses.

  • Network Error: The browser cannot communicate with the server.
  • 404 Error: The requested resource is not found.
  • 500 Error: An internal server error occurred.
  • Invalid Data: The received response cannot be processed as expected.
  • Timeout: The request takes too long to complete.

Example of Error Handling

fetch("/api/data")
    .then(response => {
        if (!response.ok) {
            throw new Error("Server error");
        }
        return response.json();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error("Error:", error.message);
    });

10. Difference Between XMLHttpRequest and Fetch API

XMLHttpRequest Fetch API
Traditional AJAX request object. Modern JavaScript request API.
Uses callbacks and event handlers. Uses Promises.
Can be more verbose. Often provides simpler syntax.
Supports request cancellation using abort(). Supports cancellation using AbortController.
Commonly used in older AJAX applications. Commonly used in modern web applications.

11. Advantages of AJAX Programming

  • Allows asynchronous communication with servers.
  • Updates page content without a full reload.
  • Improves the user experience.
  • Reduces unnecessary data transfer in suitable applications.
  • Supports JSON, XML and other response formats.
  • Makes web applications more interactive.

12. Disadvantages of AJAX Programming

  • Requires JavaScript for client-side functionality.
  • Debugging asynchronous code can be difficult.
  • Cross-origin requests require appropriate CORS configuration.
  • Incorrect handling of responses can create security issues.
  • Network failures may interrupt requests.
  • Complex applications require proper state and error management.

13. Applications of AJAX Programming

  • Live Search: Displays search suggestions while typing.
  • Online Shopping: Updates cart information dynamically.
  • Social Media: Loads new posts and notifications.
  • Online Forms: Validates user information without a full reload.
  • Email: Refreshes inbox content dynamically.
  • Dashboards: Loads updated statistics and charts.
