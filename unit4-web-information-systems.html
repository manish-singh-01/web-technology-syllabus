Web-Based Information Systems

Unit 4 – Web 2.0, Web 3.0 and Emerging Web Technologies

1. Introduction to Web-Based Information Systems

A Web-Based Information System (WBIS) is an information system that uses web technologies and internet or intranet networks to collect, process, store and distribute information.

Users can access these systems through web browsers without necessarily installing special software on their devices.

Web-based information systems are widely used in education, banking, business, healthcare and e-commerce.

Example: An online banking system allows customers to check account balances, transfer money and view transaction history through a browser.

2. Characteristics of Web-Based Information Systems

  • Browser Based: Users access the system through a web browser.
  • Centralized Data: Information is often stored on centralized or cloud-based servers.
  • Accessibility: Users can access services from different locations with network connectivity.
  • Platform Independent: Many systems work across different operating systems and devices.
  • Interactive: Users can submit information and receive results.
  • Scalability: Systems can be expanded to support more users and data.
  • Data Management: Supports storing, updating and retrieving information.
  • Security: Uses authentication and authorization to protect information.

3. Components of Web-Based Information Systems

1. Client

The client is usually a web browser used by the user to access the system.

2. Web Server

The web server receives browser requests and delivers web pages or application responses.

3. Application Server

It handles application logic and processes user requests.

4. Database Server

It stores and manages information such as user accounts, transactions and records.

5. Network

The network connects users with servers and enables data communication.

4. Architecture of Web-Based Information Systems

Many web-based information systems use a three-tier architecture.

1. Presentation Layer

This layer provides the user interface and displays information using technologies such as HTML, CSS and JavaScript.

2. Application Layer

This layer processes user requests, performs business logic and communicates with the database.

3. Data Layer

This layer stores and retrieves information using database management systems.

5. Working of Web-Based Information Systems

  1. The user opens a website using a web browser.
  2. The browser sends a request to the web server.
  3. The server forwards the request for processing.
  4. The application performs the required operations.
  5. The database is accessed when information is needed.
  6. The server generates a response.
  7. The browser displays the result to the user.

6. Technologies Used

  • HTML: Creates the structure of web pages.
  • CSS: Controls the design and layout.
  • JavaScript: Adds interactive features.
  • PHP, Python, Java and Node.js: Can be used for server-side development.
  • MySQL, PostgreSQL and MongoDB: Store and manage application data.
  • HTTP and HTTPS: Enable communication between browsers and servers.
  • Cloud Computing: Provides hosting, storage and computing resources.
  • APIs: Allow systems to exchange data with other applications.

7. Types of Web-Based Information Systems

1. E-Commerce Systems

Used for online buying and selling of products and services.

2. Online Banking Systems

Allow customers to access banking services through the internet.

3. Educational Information Systems

Manage online courses, student records, assignments and examination information.

4. Healthcare Information Systems

Help manage patient records, appointments and healthcare information.

5. Management Information Systems

Provide information to managers for planning, monitoring and decision-making.

6. Content Management Systems

Allow users to create, edit and manage website content.

8. Advantages of Web-Based Information Systems

  • Accessible from different locations.
  • Can be used across multiple devices.
  • Centralized data management simplifies updates.
  • Reduces the need to install software on every device.
  • Supports collaboration and information sharing.
  • Can be scaled according to organizational needs.
  • Provides faster access to information.
  • Can integrate with other online services.

9. Disadvantages of Web-Based Information Systems

  • Internet Dependency: Many systems require a stable network connection.
  • Security Risks: Systems may face cyberattacks and unauthorized access.
  • Privacy Issues: Sensitive information must be protected.
  • Server Failure: Server problems may make services unavailable.
  • Performance: Slow networks can affect response time.
  • Maintenance: Systems require regular updates and monitoring.

10. Applications of Web-Based Information Systems

  • Education: Online learning portals and student management systems.
  • Banking: Online transactions and account management.
  • Business: Inventory, employee and customer management.
  • Healthcare: Appointment and patient record management.
  • Government: Online applications and public services.
  • Travel: Ticket booking and hotel reservation systems.
  • E-Commerce: Online shopping and payment systems.

11. Security in Web-Based Information Systems

Security is important because these systems often store sensitive personal and organizational data.

  • Authentication: Verifies the identity of users.
  • Authorization: Controls what users are allowed to access.
  • Encryption: Protects information during transmission and storage.
  • HTTPS: Secures communication between browsers and servers.
  • Regular Updates: Helps fix known security vulnerabilities.
  • Backups: Help recover information after data loss.

12. Difference Between Traditional and Web-Based Information Systems

Important Points for Exams

  • WBIS stands for Web-Based Information System.
  • It uses web technologies to manage information.
  • Users generally access it through web browsers.
  • Its main components include client, web server, application server and database.
  • Three-tier architecture includes presentation, application and data layers.
  • HTML, CSS, JavaScript and databases are common technologies.
  • It is used in banking, education, healthcare and e-commerce.
  • Security, availability and privacy are important considerations.
