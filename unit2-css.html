CSS and Document Styling

Unit 2 | Topic 06

Learn how CSS is used to style and design HTML documents.

1. Introduction to CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the presentation and appearance of HTML documents.

CSS controls the colors, fonts, spacing, borders, backgrounds and layout of webpages.

Important Points

  • CSS stands for Cascading Style Sheets.
  • It is used to style HTML elements.
  • It separates content from presentation.
  • It helps create attractive and responsive websites.
  • One CSS file can style multiple HTML pages.

2. Syntax of CSS

A CSS rule consists of a selector and a declaration block. Each declaration contains a property and a value.

CSS Syntax

selector {
    property: value;
}

Example

h1 {
    color: blue;
    font-size: 30px;
    text-align: center;
}
  • Selector: Selects the HTML element.
  • Property: Defines what style to change.
  • Value: Defines the style value.

3. Types of CSS

CSS can be applied to HTML documents in three main ways.

A. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. 

<h1 style="color: red;">
    Welcome to CSS
</h1>

B. Internal CSS

Internal CSS is written inside the <style> tag in the head section of an HTML document. 

<head>
    <style>
        p {
            color: green;
            font-size: 18px;
        }
    </style>
</head>

C. External CSS

External CSS is written in a separate .css file and connected to an HTML document using the link element. 

<link rel="stylesheet" href="style.css">

Difference Between Types of CSS

Inline CSS Internal CSS External CSS
Written inside an HTML element. Written inside the style tag. Written in a separate CSS file.
Styles a particular element. Styles a single HTML page. Can style multiple pages.
Useful for quick styling. Useful for page-level styling. Best for maintaining large websites.

4. CSS Selectors

CSS selectors are used to select HTML elements that need to be styled.

A. Element Selector

Selects elements by their HTML tag name.

p {
    color: blue;
}

B. ID Selector

Selects an element using its unique ID.

#heading {
    color: red;
}

C. Class Selector

Selects elements belonging to a particular class.

.box {
    background-color: yellow;
}

D. Universal Selector

Selects all HTML elements.

* {
    margin: 0;
    padding: 0;
}

E. Group Selector

Applies the same styles to multiple selectors.

h1, h2, p {
    font-family: Arial;
}

5. CSS Text Properties

Text properties control the appearance and alignment of text on a webpage.

  • color: Sets the text color.
  • text-align: Aligns text.
  • text-decoration: Adds underline or other decoration.
  • text-transform: Changes text capitalization.
  • line-height: Sets the height of a line.
  • letter-spacing: Controls spacing between letters.

Example

p {
    color: black;
    text-align: justify;
    line-height: 1.6;
    letter-spacing: 1px;
}

6. CSS Font Properties

Font properties are used to control the appearance and size of text.

  • font-family: Specifies the font type.
  • font-size: Sets the font size.
  • font-weight: Controls the thickness of text.
  • font-style: Sets normal or italic text.
h1 {
    font-family: Arial, sans-serif;
    font-size: 32px;
    font-weight: bold;
    font-style: normal;
}

7. CSS Background Properties

Background properties are used to set the background color or image of HTML elements.

  • background-color: Sets the background color.
  • background-image: Sets a background image.
  • background-repeat: Controls image repetition.
  • background-position: Sets the image position.
  • background-size: Sets the image size.
body {
    background-color: lightblue;
}

.container {
    background-image: url("background.jpg");
    background-size: cover;
    background-position: center;
}

8. CSS Border Properties

The border property is used to create a border around an HTML element.

  • border-width: Sets border thickness.
  • border-style: Sets border style.
  • border-color: Sets border color.
  • border-radius: Creates rounded corners.
.box {
    border: 2px solid black;
    border-radius: 10px;
}

9. CSS Margin and Padding

Margin

Margin is the space outside an element's border. It creates distance between elements.

Padding

Padding is the space between an element's content and its border.

Example

.box {
    margin: 20px;
    padding: 15px;
    border: 2px solid black;
}

10. CSS Box Model

The CSS Box Model describes how every HTML element is represented as a rectangular box.

It consists of four main parts:

  1. Content: The actual text or image.
  2. Padding: Space around the content.
  3. Border: The boundary around padding and content.
  4. Margin: Space outside the border.

Example

.box {
    width: 200px;
    padding: 20px;
    border: 5px solid black;
    margin: 15px;
}

Remember

By default, the total width of a box includes content, left and right padding, and left and right borders. Margin adds extra outside space.

The box-sizing: border-box property makes the declared width include content, padding and border.

11. CSS Display Property

The display property specifies how an HTML element is displayed on a webpage.

  • block: Starts on a new line and generally takes available width.
  • inline: Appears within the same line.
  • inline-block: Appears inline while allowing width and height.
  • none: Hides the element and removes its layout space.
  • flex: Creates a flexible layout.
  • grid: Creates a grid layout.
.container {
    display: flex;
}

12. CSS Position Property

The position property controls how an element is positioned in a webpage.

  • static: Default positioning.
  • relative: Positioned relative to its normal position.
  • absolute: Positioned relative to its nearest positioned ancestor.
  • fixed: Positioned relative to the viewport.
  • sticky: Switches between relative and fixed-like positioning.
.box {
    position: relative;
    top: 10px;
    left: 20px;
}

13. Advantages of CSS

  • Improves the appearance of websites.
  • Saves time by reusing stylesheets.
  • Separates content from design.
  • Makes website maintenance easier.
  • Supports responsive web design.
  • Provides better control over webpage layout.

14. Practical Example of CSS

This example demonstrates how CSS styles an HTML document. 

<!DOCTYPE html>
<html>
<head>
    <title>CSS Example</title>

    <style>
        body {
            background-color: lightgray;
            font-family: Arial, sans-serif;
        }

        h1 {
            color: blue;
            text-align: center;
        }

        p {
            color: black;
            font-size: 18px;
        }

        .box {
            background-color: white;
            border: 2px solid black;
            padding: 20px;
            margin: 20px;
            border-radius: 10px;
        }
    </style>
</head>

<body>

    <h1>Welcome to CSS</h1>

    <div class="box">
        <p>
            CSS makes webpages attractive and beautiful.
        </p>
    </div>

</body>
</html>
