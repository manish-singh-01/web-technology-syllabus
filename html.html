HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure content on web pages.

01 • INTRODUCTION

What is HTML?

HTML is used to define the structure of a web page. It tells the browser how different elements such as headings, paragraphs, images, links and forms should be organized.

HTML uses elements and tags to describe the structure and meaning of web content.

02 • BASIC STRUCTURE

Basic HTML Document

<!DOCTYPE html>

<html>

<head>
    <title>My Web Page</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>This is my first web page.</p>

</body>

</html>

03 • HTML ELEMENTS

Common HTML Elements

<h1>

Heading

Used to create headings on a web page.

<p>

Paragraph

Used to display paragraphs of text.

<a>

Link

Used to create hyperlinks to other pages or resources.

<img>

Image

Used to display images on a web page.

<form>

Form

Used to collect input from users.

04 • TAGS AND ATTRIBUTES

HTML Tags and Attributes

HTML tags are keywords enclosed in angle brackets. They define elements on a web page. Most elements have an opening tag and a closing tag. 

<p class="intro">Welcome to HTML</p>
  • <p>: Opening tag.
  • class="intro": Attribute and its value.
  • Welcome to HTML: Content.
  • </p>: Closing tag.

Types of HTML Elements

  • Container elements: Usually have opening and closing tags, such as <p>.
  • Void elements: Do not have closing tags, such as <img> and <br>.

05 • PRACTICAL EXAMPLE

Example: Creating a Web Page

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>I am learning Web Technology.</p>
    <a href="https://example.com">Visit Example</a>
</body>
</html>

Expected Output

Welcome to My Website

I am learning Web Technology.

Visit Example

Explanation: The heading displays a title, the paragraph displays text, and the anchor tag creates a link.

06 • EXAM PREPARATION

Important Questions with Answers

1. What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to structure content on web pages.

2. What is the difference between a tag and an element?

A tag is markup such as <p>. An element generally includes the opening tag, content and closing tag, as in <p>Hello</p>.

3. What is the purpose of DOCTYPE?

<!DOCTYPE html> declares an HTML5 document and helps browsers render the page in standards mode.

4. What are HTML attributes?

Attributes provide additional information about elements. For example, href specifies the destination of a link in an anchor element.

5. Explain the roles of HTML, CSS and JavaScript.

HTML defines the structure, CSS controls the visual presentation, and JavaScript adds interactive behaviour.

04 • FEATURES

Important Features of HTML

  • HTML is used to structure web pages.
  • HTML documents use tags and elements.
  • HTML supports text, images, links, tables, forms and multimedia.
  • HTML works together with CSS and JavaScript to create modern websites.
  • HTML files generally use the .html file extension.
