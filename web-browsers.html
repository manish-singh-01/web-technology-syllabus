Web Browsers

TOPIC 10

Introduction to Web Browsers

Learn how web browsers retrieve web resources, interpret HTML, CSS and JavaScript, and display websites to users.

01 • INTRODUCTION

What is a Web Browser?

A web browser is a software application used to access, retrieve, and display information available on the World Wide Web.

Users can open websites, view images and videos, download files, fill out forms, and interact with web applications through a browser.

Important Points

  • A browser is used to access websites.
  • It communicates with web servers using HTTP or HTTPS.
  • It interprets HTML to create the page structure.
  • It applies CSS to control the page appearance.
  • It executes JavaScript to support interactive features.

03 • WORKING

How Does a Web Browser Work?

1. The user enters a URL in the address bar.

2. The browser determines the server address, using DNS if needed.

3. It establishes a network connection to the server.

4. It sends an HTTP or HTTPS request.

5. The server returns a response containing HTML or other resources.

6. The browser processes HTML, CSS, JavaScript, and media.

7. The browser renders the webpage on the screen.

Example

When you enter https://example.com, the browser requests the website from its server and displays the returned webpage.

04 • COMPONENTS

Main Components of a Web Browser

1. User Interface

Includes the address bar, tabs, navigation buttons, bookmarks, and menus.

2. Browser Engine

Coordinates actions between the user interface and the rendering engine.

3. Rendering Engine

Processes HTML and CSS and renders the visual representation of a webpage.

4. JavaScript Engine

Executes JavaScript code to enable dynamic and interactive webpage behavior.

5. Networking

Handles network communication and retrieval of web resources.

6. Data Storage

Manages browser data such as cookies, cached resources, and local storage.

05 • COMPARISON

Browser vs Search Engine

Web Browser

  • Software used to access and display websites.
  • Examples: Chrome, Firefox, Edge, Safari.
  • Can open a website directly through its URL.

Search Engine

  • An online service that helps users find information on the web.
  • Examples: Google Search, Bing, DuckDuckGo.
  • Returns results based on a user's search query.

Remember: Google Chrome is a browser, while Google Search is a search engine.

06 • FEATURES

Features of Web Browsers

  • Tabbed browsing.
  • Bookmarks and browsing history.
  • Download management.
  • Private browsing modes.
  • Password and permission management.
  • Developer tools for inspecting webpages.
  • Extensions and add-ons.

07 • TYPES

Types of Web Browsers

1. Desktop Browsers

Designed for desktop or laptop computers. Examples include Chrome, Firefox, and Edge.

2. Mobile Browsers

Designed for smartphones and tablets. Examples include Chrome for Android and Safari on iPhone.

3. Text-Based Browsers

Primarily display text rather than the full graphical webpage. Examples include Lynx and w3m.

08 • SECURITY

Browser Security

  • HTTPS helps encrypt communication with websites.
  • Browsers warn users about many unsafe or deceptive websites.
  • Permission controls restrict access to camera, microphone, and location.
  • Regular updates help fix security vulnerabilities.
  • Users should avoid suspicious links and untrusted downloads.

09 • ADVANTAGES

Advantages of Web Browsers

  • Provide easy access to information on the Internet.
  • Display text, images, audio, and video.
  • Allow users to interact with web applications.
  • Support online learning, communication, and shopping.
  • Offer bookmarks, history, tabs, and other productivity features.
