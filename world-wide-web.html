TOPIC 02

World Wide Web

The World Wide Web is a system of interconnected web pages and resources that can be accessed through the Internet using web browsers.

01 • OVERVIEW

What is the World Wide Web?

The World Wide Web, commonly called the Web, is a collection of interconnected documents, web pages and other resources available through the Internet.

These resources are connected using hyperlinks and can be accessed using web browsers.

02 • COMPONENTS

Main Components of the Web

01

Web Browser

Software used to access and display web pages, such as Chrome, Firefox and Edge.

02

Web Server

A server that stores and delivers web resources requested by clients.

03

Web Page

A document that can contain text, images, links, videos and other web content.

04

URL

A Uniform Resource Locator identifies the location of a resource on the Web.

05

HTTP

HTTP is a communication protocol used for transferring resources between web clients and servers.

03 • WORKING

How the Web Works

User → Browser → Request → Web Server → Response → Web Page

04 • IMPORTANT POINTS

Key Points to Remember

  • WWW stands for World Wide Web.
  • The Web works over the Internet.
  • Web browsers are used to access web pages.
  • Hyperlinks connect different web resources.
  • HTTP is commonly used for communication between browsers and web servers.
