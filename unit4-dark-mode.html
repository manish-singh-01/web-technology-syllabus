Dark Mode in Web Development

Unit 4 – Web 2.0, Web 3.0 and Emerging Web Technologies

1. Introduction to Dark Mode

Dark Mode is a user interface design feature in which the background of a website or application uses dark colours, while text and other elements use lighter colours.

It provides an alternative to the traditional light mode and gives users the option to choose a visual appearance according to their preferences.

Dark Mode is commonly used in websites, mobile applications, operating systems and software tools.

Example: YouTube, Instagram, WhatsApp and many other applications provide a Dark Mode option.

2. Features of Dark Mode

  • Dark Background: Uses dark colours such as black, grey and dark blue.
  • Light Text: Displays text in white or light shades.
  • Eye Comfort: Some users find dark interfaces more comfortable in low-light environments.
  • Customization: Allows users to select their preferred appearance.
  • Battery Saving: Can reduce power consumption on OLED and AMOLED displays when dark pixels are used.
  • Modern Design: Provides a different visual style for websites and applications.
  • System Integration: Websites can follow the user's operating system theme preference.

3. Importance of Dark Mode

  • Improves user customization and experience.
  • Provides an alternative interface for low-light environments.
  • May help reduce screen power consumption on OLED displays.
  • Supports modern website design practices.
  • Can make applications visually comfortable for some users.
  • Helps websites support different user preferences.

4. Difference Between Light Mode and Dark Mode

Light Mode Dark Mode
Uses a light background. Uses a dark background.
Usually uses dark text. Usually uses light text.
Commonly suitable for bright environments. Often preferred in low-light environments.
May use more power on some OLED displays with bright backgrounds. May save power on OLED displays.
Traditional interface appearance. Alternative modern interface appearance.

5. Technologies Used to Implement Dark Mode

  • HTML: Defines the structure of the webpage.
  • CSS: Controls background colours, text colours and visual appearance.
  • JavaScript: Allows users to switch between light and dark themes.
  • CSS Variables: Store reusable colour values for different themes.
  • Local Storage: Saves the user's selected theme in the browser.
  • Media Queries: Detect system-level theme preferences.

6. Creating Dark Mode Using HTML and CSS

CSS can be used to create a dark interface by changing the background and text colours. 

<!DOCTYPE html>
<html>
<head>
<style>

body {
    background-color: #121212;
    color: white;
    font-family: Arial, sans-serif;
}

h1 {
    color: lightblue;
}

</style>
</head>

<body>

<h1>Welcome to Dark Mode</h1>
<p>This is a dark theme webpage.</p>

</body>
</html>

In this example, the body background becomes dark and the text colour becomes white.

7. Creating a Dark Mode Toggle Using JavaScript

JavaScript can be used to switch between light and dark themes when a user clicks a button. 

<!DOCTYPE html>
<html>
<head>

<style>

body {
    background: white;
    color: black;
    font-family: Arial;
    transition: 0.3s;
}

.dark {
    background: #121212;
    color: white;
}

</style>

</head>

<body>

<h2>Dark Mode Example</h2>

<button onclick="toggleMode()">
    Toggle Dark Mode
</button>

<script>

function toggleMode() {
    document.body.classList.toggle("dark");
}

</script>

</body>
</html>

Explanation: When the user clicks the button, JavaScript adds or removes the dark class from the body element.

8. Using CSS Variables for Dark Mode

CSS variables make it easier to manage colours and maintain consistent themes across a website. 

:root {
    --background: white;
    --text: black;
}

.dark {
    --background: #121212;
    --text: white;
}

body {
    background: var(--background);
    color: var(--text);
}

CSS variables allow developers to change multiple design properties by updating a small set of values.

9. Advantages of Dark Mode

  • Provides users with theme customization.
  • Can improve visual comfort in low-light environments for some users.
  • May reduce battery usage on OLED and AMOLED displays.
  • Provides an alternative modern appearance.
  • Can improve the experience for users who prefer dark interfaces.
  • Can be implemented using HTML, CSS and JavaScript.

10. Disadvantages of Dark Mode

  • Some users find light text on dark backgrounds difficult to read.
  • Poor colour contrast can reduce accessibility.
  • Images and graphics may require separate styling adjustments.
  • Developers need to test both themes properly.
  • Dark Mode does not guarantee better battery life on every display.
  • Some colours may appear different in dark themes.

11. Best Practices for Dark Mode

  • Maintain sufficient contrast between text and background.
  • Use readable font sizes and styles.
  • Provide a clear option to switch between themes.
  • Save the user's theme preference when appropriate.
  • Test buttons, forms, images and links in both themes.
  • Use CSS variables to manage theme colours.
  • Respect the operating system's theme preference.
  • Ensure that the design remains accessible.

12. Applications of Dark Mode

  • Social Media: Instagram, Facebook and YouTube.
  • Messaging: WhatsApp and Telegram.
  • Development Tools: Visual Studio Code and code editors.
  • Operating Systems: Windows, Android and macOS.
  • Websites: Blogs, dashboards and online platforms.
  • Entertainment: Video and music streaming applications.
