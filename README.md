# 🌐 Web Technology Syllabus Website

A complete educational website developed using HTML5 and CSS3 to organize and present Web Technology syllabus topics from Unit 1 to Unit 5.

## 🚀 Live Demo

**[Visit Website](https://manish-singh-01.github.io/web-technology-syllabus/)**

## 📖 About the Project

The Web Technology Syllabus Website is designed to help students learn and revise important concepts of Web Technology in an organized and easy-to-understand format.

The website contains five units covering fundamental web concepts, web development technologies, web services, Web 2.0 and emerging web technologies.

## ✨ Features

- Five organized syllabus units.
- Individual topic pages for easy learning.
- Simple and user-friendly navigation.
- Structured explanations of important concepts.
- Examples, tables and exam-oriented questions.
- Quick revision sections.
- Responsive layout for different screen sizes.
- Hosted online using GitHub Pages.

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling and layout.
- GitHub – Source code hosting.
- GitHub Pages – Website deployment.

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it using Live Server or open it directly in a browser.
