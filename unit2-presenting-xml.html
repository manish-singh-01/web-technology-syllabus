Presenting XML

Unit 2 | Topic 10

Learn how XML documents are displayed, formatted and transformed.

1. Introduction to Presenting XML

XML stands for Extensible Markup Language. It is used to store and transport structured data. XML focuses on describing data rather than displaying it.

Presenting XML means displaying XML data in a readable and understandable format. XML can be presented using CSS, XSLT and other processing techniques.

Important Points

  • XML stores and describes structured data.
  • XML does not define how data should look on a webpage.
  • CSS can be used to style XML elements.
  • XSLT can transform XML into HTML or other formats.
  • Browsers can display XML documents directly.

2. Methods of Presenting XML

There are different methods used to present XML documents in a readable format.

1. Direct Browser Display

Modern web browsers can display XML documents directly. They generally show the document structure in a tree-like format.

2. Using CSS

CSS (Cascading Style Sheets) is used to control the appearance of XML elements, including colors, fonts, spacing and display properties.

3. Using XSLT

XSLT (Extensible Stylesheet Language Transformations) is used to transform XML documents into HTML, plain text or other XML documents.

3. Direct Display of XML in a Browser

An XML file can be opened directly in a modern web browser. The browser displays the XML tags and their corresponding data.

Example: student.xml

<?xml version="1.0" encoding="UTF-8"?>

<student>
    <name>Rahul</name>
    <rollno>101</rollno>
    <course>B.Tech CSE</course>
    <university>Quantum University</university>
</student>

When this file is opened in a browser, the browser displays the XML structure and its data.

4. Presenting XML Using CSS

CSS can be linked with an XML document to define the visual presentation of its elements.

Steps to Apply CSS to XML

  1. Create an XML document.
  2. Create a CSS stylesheet.
  3. Link the CSS file using an XML stylesheet processing instruction.
  4. Open the XML document in a compatible browser.

Example: student.xml

<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/css" href="style.css"?>

<student>
    <name>Rahul</name>
    <course>B.Tech CSE</course>
    <rollno>101</rollno>
</student>

Example: style.css

student {
    display: block;
    background-color: lightyellow;
    padding: 20px;
    font-family: Arial;
}

name {
    display: block;
    color: blue;
    font-size: 24px;
    font-weight: bold;
}

course, rollno {
    display: block;
    color: green;
    margin-top: 10px;
}

In this example, CSS changes the appearance of XML elements by applying colors, fonts and spacing.

5. Presenting XML Using XSLT

XSLT stands for Extensible Stylesheet Language Transformations. It is a language used to transform XML documents into other formats.

Uses of XSLT

  • Transforms XML data into HTML webpages.
  • Changes the structure of XML documents.
  • Selects specific information from XML data.
  • Sorts and filters XML data.
  • Can produce text or another XML document.

Basic XSLT Components

  • xsl:stylesheet: Defines an XSLT stylesheet.
  • xsl:template: Defines a template for matching nodes.
  • xsl:value-of: Extracts the value of a selected node.
  • xsl:for-each: Processes each selected node.
  • xsl:apply-templates: Applies templates to selected nodes.
  • xsl:sort: Sorts selected nodes.

6. XML to HTML Transformation Using XSLT

XSLT can convert XML data into an HTML table so that users can view the information easily.

Step 1: students.xml

<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="students.xsl"?>

<students>
    <student>
        <name>Rahul</name>
        <rollno>101</rollno>
        <course>CSE</course>
    </student>

    <student>
        <name>Amit</name>
        <rollno>102</rollno>
        <course>IT</course>
    </student>
</students>

Step 2: students.xsl

<?xml version="1.0"?>

<xsl:stylesheet version="1.0"
xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

    <xsl:template match="/">
        <html>
        <body>
            <h2>Student Information</h2>

            <table border="1">
                <tr>
                    <th>Name</th>
                    <th>Roll No</th>
                    <th>Course</th>
                </tr>

                <xsl:for-each select="students/student">
                    <tr>
                        <td>
                            <xsl:value-of select="name"/>
                        </td>
                        <td>
                            <xsl:value-of select="rollno"/>
                        </td>
                        <td>
                            <xsl:value-of select="course"/>
                        </td>
                    </tr>
                </xsl:for-each>
            </table>
        </body>
        </html>
    </xsl:template>

</xsl:stylesheet>

When the XML file is opened in a browser that supports XSLT processing, the XML data is transformed into an HTML table.

7. Difference Between CSS and XSLT

CSS XSLT
CSS stands for Cascading Style Sheets. XSLT stands for Extensible Stylesheet Language Transformations.
Controls the appearance of elements. Transforms XML into another format.
Does not normally change document structure. Can change the structure and arrangement of data.
Used for colors, fonts and layouts. Used for filtering, sorting and transforming data.
Uses CSS selectors. Uses XPath expressions to select XML nodes.

8. Advantages of Presenting XML

  • Makes structured data easier to understand.
  • Improves the readability of XML documents.
  • Allows XML data to be displayed in webpages.
  • Supports data transformation into different formats.
  • Separates data from its presentation.
  • Helps in sharing data between different applications.

9. Applications of XML Presentation

  • Displaying student records.
  • Presenting product information in e-commerce systems.
  • Displaying data from web services.
  • Generating reports from XML files.
  • Converting structured data into HTML pages.
  • Sharing information between different systems.

Quick Revision

  • XML – Extensible Markup Language.
  • Presenting XML – Displaying XML data in a readable format.
  • CSS – Used to style XML elements.
  • XSLT – Used to transform XML documents.
  • XPath – Used to select nodes in XML documents.
  • xsl:template – Defines a transformation template.
  • xsl:value-of – Extracts node values.
  • xsl:for-each – Processes selected nodes repeatedly.
  • XML + XSLT – Can produce HTML output.
