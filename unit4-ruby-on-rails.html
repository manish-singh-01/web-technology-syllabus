Ruby on Rails

Unit 4 – Web 2.0, Web 3.0 and Emerging Web Technologies

1. Introduction to Ruby on Rails

Ruby on Rails, commonly known as Rails, is an open-source web application framework written in the Ruby programming language.

It is used to develop database-driven and dynamic web applications quickly and efficiently. Rails provides built-in tools, libraries and conventions that simplify web development.

Ruby on Rails follows the principle of Convention over Configuration (CoC) and the Don't Repeat Yourself (DRY) principle.

2. What is Ruby?

Ruby is a high-level, interpreted, general-purpose programming language. It was designed to be simple, readable and productive for programmers.

Features of Ruby

  • Simple and readable syntax.
  • Object-oriented programming language.
  • Dynamic typing.
  • Supports automatic memory management.
  • Provides a large collection of libraries.
  • Can be used for web development and scripting.

3. Features of Ruby on Rails

  • Open Source: Rails is freely available and can be modified.
  • MVC Architecture: Separates application logic into Model, View and Controller.
  • Convention over Configuration: Reduces the need for unnecessary configuration.
  • DRY Principle: Avoids repeating the same code unnecessarily.
  • Database Support: Provides tools for database operations.
  • Built-in Libraries: Offers reusable components for common tasks.
  • Rapid Development: Helps developers build applications efficiently.
  • Routing System: Maps incoming web requests to application actions.

4. MVC Architecture in Ruby on Rails

Ruby on Rails follows the Model-View-Controller (MVC) architectural pattern. It separates an application into three main components.

1. Model

The Model manages application data and business logic. It communicates with the database and handles data-related operations.

2. View

The View represents the user interface. It displays information to users through HTML templates and other presentation elements.

3. Controller

The Controller receives user requests, communicates with the Model and selects the appropriate View to generate a response.

5. Important Principles of Rails

1. Convention over Configuration (CoC)

This principle means that Rails provides default conventions and standard rules so developers do not need to configure every part of an application manually.

2. Don't Repeat Yourself (DRY)

DRY means that the same information or code should not be repeated unnecessarily. Reusable code makes applications easier to maintain.

6. Important Components of Ruby on Rails

  • Active Record: Handles database operations and object-relational mapping (ORM).
  • Action Controller: Processes incoming requests and controls application flow.
  • Action View: Handles the presentation layer and templates.
  • Action Routing: Maps URLs to controller actions.
  • Active Support: Provides useful extensions and helper methods for Ruby.
  • Migration: Manages changes to database structure.

7. Working of Ruby on Rails

  1. The user sends a request through a web browser.
  2. The Rails routing system identifies the correct route.
  3. The Controller receives and processes the request.
  4. The Controller communicates with the Model if data is required.
  5. The Model interacts with the database.
  6. The Controller selects the appropriate View.
  7. The View generates the response for the browser.

9. Advantages of Ruby on Rails

  • Speeds up web application development.
  • Provides reusable components and libraries.
  • Follows the MVC architecture.
  • Supports database integration.
  • Reduces repetitive programming work.
  • Has a large developer community.
  • Supports testing and application maintenance.

10. Disadvantages of Ruby on Rails

  • May consume more resources for some applications.
  • Can have a learning curve for beginners.
  • Performance may require optimization for demanding workloads.
  • Some projects may require additional libraries or configuration.
  • Its conventions may feel restrictive in highly customized applications.

11. Applications of Ruby on Rails

  • E-commerce: Online shopping applications.
  • Social Platforms: Community and networking applications.
  • Content Management: Websites that manage digital content.
  • Business Applications: Internal management systems.
  • Web Portals: Dynamic websites and online services.
  • Startups: Rapid development of web application prototypes.

12. Ruby on Rails vs Traditional Web Development

Ruby on Rails Traditional Development
Provides a ready-made web framework. May require developers to build more components manually.
Follows MVC architecture. Architecture depends on the chosen development approach.
Uses conventions to reduce configuration. May require more manual configuration.
Includes tools for database operations. Database integration depends on selected technologies.
Encourages rapid development. Development speed depends on the tools and framework used.

Important Points for Exams

  • Rails follows the MVC architecture.
  • MVC stands for Model, View and Controller.
  • CoC stands for Convention over Configuration.
  • DRY stands for Don't Repeat Yourself.
  • Active Record handles database-related operations.
  • Rails supports rapid web application development.
