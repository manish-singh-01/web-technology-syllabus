MIME

TOPIC 07

Multipurpose Internet Mail Extensions

Learn how MIME allows email systems to transfer multimedia content such as images, audio, video, documents, and attachments.

01 • INTRODUCTION

What is MIME?

MIME stands for Multipurpose Internet Mail Extensions. It is an Internet standard that extends the format of email messages to support different types of content beyond plain ASCII text.

MIME allows users to send images, audio, video, PDF documents, HTML content, and other attachments through email.

Important Points

  • MIME stands for Multipurpose Internet Mail Extensions.
  • It extends traditional email message formats.
  • It supports multimedia attachments.
  • It specifies the content type and encoding of messages.
  • It is commonly used with SMTP.

02 • PURPOSE

Why is MIME Needed?

Traditional email systems were originally designed mainly for 7-bit ASCII text. They could not directly represent many types of multimedia and international text content.

MIME was introduced to overcome these limitations by describing the structure, content type, and transfer encoding of email messages.

  • Supports non-ASCII text.
  • Allows sending images and documents.
  • Supports audio and video attachments.
  • Allows multiple content parts in one email.
  • Supports HTML-formatted emails.

03 • WORKING

How Does MIME Work?

MIME adds special headers to email messages that describe the type and format of their content.

1. User creates an email with text or attachments.

2. Email client identifies the content types.

3. MIME headers describe the message parts.

4. Attachments are encoded when necessary.

5. SMTP transfers the email message.

6. Receiver decodes and displays the content.

Remember

MIME describes and formats email content, while SMTP is responsible for transferring email between mail servers.

04 • MIME HEADERS

Important MIME Headers

  • MIME-Version: Specifies the MIME version, usually 1.0.
  • Content-Type: Describes the type of data in the message.
  • Content-Transfer-Encoding: Specifies how content is encoded for transmission.
  • Content-Disposition: Indicates whether content is displayed inline or treated as an attachment.
  • Content-ID: Provides an identifier for a message part, often used for embedded content.

05 • MIME TYPES

Common MIME Content Types

A MIME type tells the receiving application what kind of content is being transmitted. 

text/plain
text/html
image/jpeg
image/png
audio/mpeg
video/mp4
application/pdf
application/json
multipart/mixed

Examples

  • text/plain – Plain text
  • text/html – HTML document
  • image/jpeg – JPEG image
  • application/pdf – PDF file
  • multipart/mixed – Multiple message parts, often with attachments

06 • PRACTICAL EXAMPLE

Example of a MIME Email

From: sender@example.com
To: receiver@example.com
Subject: MIME Example
MIME-Version: 1.0
Content-Type: text/html; charset=UTF-8

<html>
<body>
    <h2>Hello Student!</h2>
    <p>Welcome to Web Technology.</p>
</body>
</html>

In this example, the Content-Type header tells the email client that the message body contains HTML content.

07 • COMPARISON

Difference Between MIME and SMTP

MIME

  • Defines email content format.
  • Supports multimedia and attachments.
  • Specifies content types and encoding.

SMTP

  • Transfers outgoing email messages.
  • Communicates between mail servers.
  • Uses commands for mail delivery.

08 • ADVANTAGES

Advantages of MIME

  • Supports multimedia email messages.
  • Allows multiple attachments.
  • Supports international character sets.
  • Enables HTML email formatting.
  • Provides standardized content identification.
