Unit 4: Web 2.0, Web 3.0 and Emerging Web Technologies

Web Technology – Complete Study Notes

About Unit 4

This unit introduces Web 2.0 and Web 3.0 technologies, including interactive websites, social networking, blogs, wikis, AJAX, RSS, Ruby on Rails, Open APIs, Semantic Web, RDF, search engines and recommender systems. It also covers emerging technologies such as Blockchain, Edge Computing and Dark Mode in Web Development.
