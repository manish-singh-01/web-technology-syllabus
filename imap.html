IMAP

TOPIC 08

Internet Message Access Protocol

Learn how IMAP allows users to access, manage, and synchronize email messages across multiple devices.

01 • INTRODUCTION

What is IMAP?

IMAP stands for Internet Message Access Protocol. It is an email protocol that allows users to access and manage their emails stored on a mail server.

With IMAP, emails generally remain on the server, and changes such as reading, deleting, or moving messages can synchronize across connected devices.

Important Points

  • Full form: Internet Message Access Protocol.
  • Used to access and manage emails on a server.
  • Supports synchronization across multiple devices.
  • Allows users to organize messages into folders.
  • Works with an email client and a mail server.

02 • PURPOSE

Why is IMAP Needed?

Users often check their email using multiple devices, such as laptops, smartphones, and tablets. IMAP helps keep their email view consistent across these devices.

  • Access emails from different devices.
  • Keep messages stored on the mail server.
  • Synchronize read and unread status.
  • Organize emails into folders.
  • Manage messages without downloading every email permanently.

03 • WORKING

How Does IMAP Work?

1. The user opens an email application.

2. The application connects to the mail server using IMAP.

3. The server provides the mailbox information.

4. The user reads, searches, or organizes emails.

5. Changes are synchronized with the server.

6. Other connected devices can see the updated mailbox.

Example

Suppose you read an email on your laptop. When you open the same mailbox on your phone, that email can already appear as read because the status was synchronized through IMAP.

04 • PORT NUMBERS

IMAP Port Numbers

  • Port 143: Standard IMAP port, commonly used without implicit TLS; STARTTLS may be supported.
  • Port 993: IMAP over implicit TLS, providing an encrypted connection.

Remember: 143 is the standard IMAP port, while 993 is commonly used for IMAP with TLS encryption.

05 • FEATURES

Main Features of IMAP

  • Server-based email storage.
  • Access to the same mailbox from multiple devices.
  • Email folder and mailbox management.
  • Synchronization of message status and changes.
  • Search and selective message retrieval.

06 • COMPARISON

Difference Between IMAP and POP3

IMAP

  • Manages email while keeping the mailbox on the server.
  • Synchronizes changes across devices.
  • Supports server-side folders and mailbox organization.
  • Common ports: 143 and 993.

POP3

  • Typically downloads messages to an email client.
  • May remove messages from the server, depending on settings.
  • Does not provide IMAP-style mailbox synchronization.
  • Common ports: 110 and 995.

Exam tip: IMAP is generally preferred when the same email account is used on multiple devices.

07 • ADVANTAGES

Advantages of IMAP

  • Emails can be accessed from multiple devices.
  • Mailbox changes are synchronized.
  • Messages remain available on the server.
  • Emails can be organized into folders.
  • Users can retrieve selected messages when needed.

08 • LIMITATIONS

Limitations of IMAP

  • Internet access is generally needed for full synchronization.
  • Server storage limits may apply.
  • Large mailboxes can take time to synchronize.
  • Offline access depends on what the email client has cached or downloaded.
