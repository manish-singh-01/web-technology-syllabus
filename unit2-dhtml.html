Dynamic HTML with JavaScript

Unit 2 | Topic 07

Learn how JavaScript makes webpages interactive and dynamic.

1. Introduction to Dynamic HTML

Dynamic HTML (DHTML) is a combination of HTML, CSS, JavaScript and the Document Object Model (DOM) used to create interactive and dynamic webpages.

It allows webpage content, style and layout to change dynamically without reloading the entire webpage.

Important Points

  • DHTML stands for Dynamic HTML.
  • It is not a separate programming language.
  • It combines HTML, CSS, JavaScript and DOM.
  • It makes webpages interactive.
  • It can update content without a full page reload.

2. Components of DHTML

A. HTML

HTML provides the basic structure and content of a webpage.

B. CSS

CSS controls the design, colors, fonts and layout of webpage elements.

C. JavaScript

JavaScript is a scripting language used to add functionality and interactive behavior to webpages.

D. DOM

The Document Object Model represents an HTML document as a tree of objects. JavaScript can use the DOM to access and modify webpage elements.

Components Summary

DHTML =
HTML + CSS + JavaScript + DOM

3. Introduction to JavaScript

JavaScript is a high-level scripting language commonly used to make websites interactive. It runs in web browsers and can respond to user actions.

Features of JavaScript

  • Lightweight and flexible scripting language.
  • Supports event handling.
  • Can modify HTML and CSS dynamically.
  • Supports functions and objects.
  • Can validate user input.
  • Can communicate with web servers.

4. Adding JavaScript to HTML

JavaScript can be added to HTML in three main ways.

A. Inline JavaScript

JavaScript code is written directly inside an HTML event attribute. 

<button onclick="alert('Hello!')">
    Click Me
</button>

B. Internal JavaScript

JavaScript is written inside the <script> tag in an HTML document. 

<script>
    alert("Welcome to JavaScript");
</script>

C. External JavaScript

JavaScript is stored in a separate .js file and connected to HTML using the script tag. 

<script src="script.js"></script>

5. JavaScript Variables

Variables are used to store data values in JavaScript. JavaScript provides three commonly used declarations:

  • var: Function-scoped variable declaration.
  • let: Block-scoped variable declaration.
  • const: Block-scoped declaration that cannot be reassigned.

Example

var name = "Manish";

let age = 21;

const course = "CSE";

document.write(name);

6. JavaScript Functions

A function is a reusable block of code that performs a particular task. It executes when it is called.

Example

function greet() {
    alert("Welcome to DHTML!");
}

greet();

Advantages of Functions

  • Reduce code repetition.
  • Make programs easier to understand.
  • Improve code organization.
  • Allow code to be reused.

7. JavaScript Events

Events are actions or occurrences that happen in the browser. JavaScript can respond to these events.

Common JavaScript Events

  • onclick: Occurs when an element is clicked.
  • ondblclick: Occurs when an element is double-clicked.
  • onmouseover: Occurs when the mouse pointer moves over an element.
  • onmouseout: Occurs when the mouse pointer leaves an element.
  • onkeydown: Occurs when a keyboard key is pressed.
  • onchange: Occurs when an input value is changed and committed.
  • onload: Occurs when a resource or page finishes loading.
  • onsubmit: Occurs when a form is submitted.

Example

<button onclick="alert('Button Clicked')">
    Click Here
</button>

8. Event Handling

Event handling means executing JavaScript code in response to a particular event.

Example

<button id="myButton">
    Click Me
</button>

<script>
    document.getElementById("myButton")
        .addEventListener("click", function() {
            alert("Welcome to DHTML!");
        });
</script>

9. Document Object Model (DOM)

DOM stands for Document Object Model. It represents an HTML document as a tree structure of objects.

JavaScript uses the DOM to access, change, add or remove HTML elements and their attributes.

Common DOM Methods

  • getElementById(): Selects an element by its ID.
  • getElementsByClassName(): Selects elements by class name.
  • getElementsByTagName(): Selects elements by tag name.
  • querySelector(): Selects the first matching CSS selector.
  • querySelectorAll(): Selects all matching CSS selectors.
  • createElement(): Creates a new HTML element.
  • remove(): Removes an element.

Example

document.getElementById("heading")
    .innerHTML = "Welcome to DHTML";

10. Changing HTML Content Dynamically

JavaScript can change the content of HTML elements using properties such as innerHTML and textContent.

Example

<h2 id="heading">Old Text</h2>

<button onclick="changeText()">
    Change Text
</button>

<script>
function changeText() {
    document.getElementById("heading")
        .textContent = "New Text";
}
</script>

11. Changing CSS Dynamically

JavaScript can change the CSS style of an HTML element through the DOM style property.

Example

<p id="text">Hello World</p>

<button onclick="changeColor()">
    Change Color
</button>

<script>
function changeColor() {
    document.getElementById("text")
        .style.color = "red";
}
</script>

12. Creating HTML Elements Dynamically

JavaScript can create new HTML elements using the createElement() method.

Example

<div id="container"></div>

<script>
let para = document.createElement("p");

para.textContent = "This is a new paragraph.";

document.getElementById("container")
    .appendChild(para);
</script>

13. Form Validation Using JavaScript

JavaScript can validate user input before a form is submitted. It helps check whether required information has been entered correctly.

Example

<form onsubmit="return validateForm()">

    <input type="text" id="username"
           placeholder="Enter Name">

    <button type="submit">Submit</button>

</form>

<script>
function validateForm() {

    let name = document.getElementById("username").value;

    if (name === "") {
        alert("Please enter your name");
        return false;
    }

    alert("Form submitted successfully");
    return true;
}
</script>

14. Advantages of DHTML

  • Makes webpages interactive and attractive.
  • Allows dynamic changes to webpage content.
  • Can update elements without a full page reload.
  • Supports event-based interaction.
  • Improves user experience.
  • Can be used to create animations and interactive menus.

15. Applications of DHTML

  • Interactive navigation menus.
  • Form validation.
  • Image sliders and animations.
  • Dynamic content updates.
  • Interactive buttons and pop-up messages.
  • Interactive web applications.
