Wikis

Unit 4 – Web 2.0, Web 3.0 and Emerging Web Technologies

1. Introduction to Wikis

A Wiki is a type of website or web application that allows multiple users to create, edit, organize and share information collaboratively.

The word Wiki comes from the Hawaiian word "Wiki-Wiki", which means quick. Wikis make it easy for users to add and update information without requiring advanced programming knowledge.

Wikipedia is one of the most popular examples of a Wiki. It allows contributors from different parts of the world to create and improve encyclopedia articles.

2. Features of Wikis

  • Collaborative Editing: Multiple users can edit and improve the same content.
  • Easy Content Creation: Users can create pages without advanced coding skills.
  • Version History: Previous versions of pages can be viewed and restored.
  • Hyperlinks: Wiki pages can be connected through internal and external links.
  • Search Functionality: Users can search for specific information.
  • Knowledge Sharing: Users can contribute information and share knowledge.
  • Community Participation: Contributors can work together to maintain information.
  • Access Control: Some wikis allow administrators to control who can view or edit pages.

3. Components of a Wiki

1. Wiki Pages

Wiki pages contain information, articles, images and other content related to a particular topic.

2. Edit Option

The edit option allows authorized users to modify existing content or add new information.

3. Page History

Page history records changes made by different contributors and helps users track previous versions.

4. Discussion Section

A discussion section allows contributors to communicate about changes and improvements to pages.

5. Search Tool

The search tool helps users find specific pages and information quickly.

6. User Management

Administrators can manage user permissions and control editing access.

4. Working of a Wiki

A Wiki works through collaborative content creation and editing. The general process is:

  1. A user opens a Wiki website.
  2. The user searches for an existing page or creates a new page.
  3. The user adds or edits information.
  4. The changes are saved in the Wiki system.
  5. Other users can review or improve the content.
  6. The page history records changes for future reference.

5. Types of Wikis

1. Public Wikis

Public Wikis are accessible to everyone. Depending on their settings, users may be allowed to edit pages. Example: Wikipedia.

2. Private Wikis

Private Wikis restrict access to selected users or organizations. They are commonly used for internal information sharing.

3. Educational Wikis

Educational Wikis are used by students and teachers to share study materials, notes and academic knowledge.

4. Corporate Wikis

Corporate Wikis are used by organizations to store company documents, policies, procedures and project information.

5. Community Wikis

Community Wikis allow people with common interests to contribute and maintain shared information.

6. Examples of Wiki Platforms

1. Wikipedia

Wikipedia is a free online encyclopedia where users can collaboratively create and edit articles.

2. Wikibooks

Wikibooks provides free educational textbooks and learning resources.

3. Wiktionary

Wiktionary is a free dictionary project that provides meanings, definitions and language information.

4. MediaWiki

MediaWiki is open-source Wiki software used to build collaborative knowledge websites.

5. Confluence

Confluence is a collaboration and documentation platform used by teams and organizations.

7. Advantages of Wikis

  • Encourages collaboration and teamwork.
  • Makes information sharing easy.
  • Allows quick editing and updating of content.
  • Maintains a history of changes.
  • Supports online learning and education.
  • Helps organizations manage shared knowledge.
  • Reduces duplication of information.

8. Disadvantages of Wikis

  • Incorrect Information: Users may add inaccurate content.
  • Vandalism: Some users may intentionally damage or delete information.
  • Content Management: Maintaining large Wiki websites can be difficult.
  • Conflicting Edits: Different contributors may disagree about content.
  • Security Issues: Poor access control may allow unauthorized changes.
  • Quality Control: Information may require verification and reliable references.

10. Applications of Wikis

  • Education: Sharing notes, study materials and learning resources.
  • Business: Maintaining company documentation and policies.
  • Research: Sharing knowledge and research information.
  • Software Development: Maintaining technical documentation.
  • Communities: Creating shared knowledge bases for common interests.
  • Project Management: Sharing project details and team information.
