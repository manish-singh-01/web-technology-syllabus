TOPIC 03

Images in HTML

Learn how to add images to webpages using HTML, control their size, provide alternative text, and create responsive images.

01 • INTRODUCTION

What is an HTML Image?

Images are visual elements used to make webpages more attractive, informative, and interactive. HTML provides the <img> tag to display images on a webpage.

Important Points

  • The <img> tag is used to display images.
  • It is an empty element and does not require a closing tag.
  • The src attribute specifies the image location.
  • The alt attribute provides alternative text.
  • Images can be stored locally or loaded from a URL.

02 • BASIC IMAGE TAG

How to Insert an Image?

The basic syntax of the HTML image tag is: 

<img src="image.jpg" alt="Description of image">

Here, src specifies the image file and alt provides text describing the image.

Example

<img src="flower.jpg" alt="A beautiful flower">

03 • IMAGE ATTRIBUTES

Important Attributes of the Image Tag

1. src

Specifies the path or URL of the image.

src="photo.jpg"

2. alt

Provides alternative text if the image cannot be displayed and helps screen-reader users.

alt="Student using a laptop"

3. width

Specifies the image width.

width="400"

4. height

Specifies the image height.

height="250"

5. title

Provides additional advisory information about an image.

title="College Campus"

04 • IMAGE SIZE

Setting Image Height and Width

HTML allows the width and height of an image to be specified. CSS can also be used to control image dimensions. 

<img
    src="college.jpg"
    alt="College building"
    width="400"
    height="250"
>

It is important to maintain the image's original aspect ratio to avoid distortion.

05 • IMAGE PATHS

Types of Image Paths

1. Relative Path

Specifies the image location relative to the current HTML file.

src="images/photo.jpg"

2. Parent Folder Path

Uses ../ to move to the parent directory.

src="../images/photo.jpg"

3. Absolute URL

Uses the complete URL of an image hosted on another server.

src="https://example.com/photo.jpg"

Example Folder Structure

web technology/
│
├── unit2-images.html
├── style.css
│
└── images/
    ├── flower.jpg
    └── college.png

To display flower.jpg from unit2-images.html, use:

src="images/flower.jpg"

06 • FIGURE AND FIGCAPTION

Figure and Figcaption Tags

The <figure> element groups an image or other self-contained content. The <figcaption> element provides its caption. 

<figure>
    <img src="nature.jpg"
         alt="Beautiful green forest">

    <figcaption>
        A beautiful forest.
    </figcaption>
</figure>

07 • RESPONSIVE IMAGES

Responsive Images Using CSS

Responsive images adjust to fit different screen sizes without overflowing their containers. 

img {
    max-width: 100%;
    height: auto;
}

The max-width property prevents an image from becoming wider than its container, while height: auto maintains its aspect ratio.

08 • PICTURE ELEMENT

Using the Picture Element

The <picture> element allows browsers to select different image sources based on screen size or supported image formats. 

<picture>
    <source
        media="(max-width: 600px)"
        srcset="small.jpg">

    <source
        media="(min-width: 601px)"
        srcset="large.jpg">

    <img src="large.jpg" alt="Nature view">
</picture>

09 • IMAGE FORMATS

Common Image Formats

JPEG / JPG

Commonly used for photographs and compressed images.

PNG

Supports transparency and lossless compression.

GIF

Supports simple animations and limited colors.

SVG

A vector format suitable for icons, logos, and illustrations.

WebP

A modern image format that supports lossy and lossless compression.

10 • PRACTICAL EXAMPLE

Complete HTML Image Example

<!DOCTYPE html>
<html>
<head>
    <title>My Image Page</title>
</head>

<body>

    <h2>My College</h2>

    <img
        src="images/college.jpg"
        alt="College Building"
        width="400"
        height="250"
    >

</body>
</html>
