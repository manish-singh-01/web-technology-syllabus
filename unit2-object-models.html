Object Models

Unit 2 | Topic 09

Understand how web documents are represented and manipulated using object models.

1. Introduction to Object Models

An Object Model represents a document or application as a collection of objects. Each object contains properties and methods that allow programs to access and manipulate information.

In web technology, object models help JavaScript interact with HTML documents, browser windows, forms and other webpage components.

Important Points

  • An object represents an element or component.
  • Properties describe an object's characteristics.
  • Methods define the actions an object can perform.
  • Object models allow dynamic interaction with webpages.
  • DOM and BOM are important browser object models.

2. Types of Object Models

A. Document Object Model (DOM)

DOM stands for Document Object Model. It represents an HTML or XML document as a hierarchical tree of objects. JavaScript can use the DOM to access and modify document content, structure and styles.

B. Browser Object Model (BOM)

BOM stands for Browser Object Model. It provides objects that allow JavaScript to interact with the browser environment outside the document itself.

C. Event Model

The event model allows programs to respond to user actions such as mouse clicks, keyboard input and form submissions.

3. Document Object Model (DOM)

The DOM is a programming interface for HTML and XML documents. It represents the document as a tree of nodes and objects.

Features of DOM

  • Represents documents in a tree structure.
  • Provides access to HTML elements.
  • Allows modification of document content.
  • Allows HTML attributes to be changed.
  • Supports dynamic webpage updates.
  • Supports event handling.

4. DOM Tree Structure

The DOM represents an HTML document in the form of a tree. Each part of the document is represented by a node.

Example HTML Document

<html>
    <head>
        <title>My Website</title>
    </head>

    <body>
        <h1>Welcome</h1>
        <p>Hello World</p>
    </body>
</html>

DOM Tree Representation

             Document
                 |
               html
              /    \
           head    body
            |      /  \
          title   h1   p
            |      |   |
        My Website Welcome Hello World

In this structure, the document is the root, html is its child, and head and body are child elements of html.

5. Types of DOM Nodes

A DOM node is an individual component of the document tree.

  • Document Node: Represents the entire document.
  • Element Node: Represents an HTML element.
  • Text Node: Represents text inside an element.
  • Attribute Node: Represents an element attribute.
  • Comment Node: Represents an HTML comment.

6. DOM Properties

Properties provide information about DOM objects and allow access to their values.

  • innerHTML: Gets or sets HTML content.
  • textContent: Gets or sets text content.
  • id: Gets or sets an element's ID.
  • className: Gets or sets an element's class name.
  • style: Accesses an element's inline CSS styles.
  • parentElement: Returns the parent element.
  • children: Returns an element's child elements.

Example

let heading = document.getElementById("title");

heading.textContent = "New Heading";

heading.style.color = "blue";

7. DOM Methods

Methods are functions provided by DOM objects to perform operations on a document.

  • getElementById(): Selects an element using its ID.
  • getElementsByTagName(): Selects elements by tag name.
  • getElementsByClassName(): Selects elements by class name.
  • querySelector(): Selects the first matching CSS selector.
  • querySelectorAll(): Selects all matching CSS selectors.
  • createElement(): Creates a new element.
  • appendChild(): Adds a child node.
  • removeChild(): Removes a child node.

Example

let element = document.getElementById("demo");

element.textContent = "Hello DOM!";

8. Browser Object Model (BOM)

BOM stands for Browser Object Model. It provides JavaScript with objects to interact with the browser window and its environment.

Important BOM Objects

  • window: Represents the browser window.
  • navigator: Provides information about the browser environment.
  • location: Provides information about the current URL.
  • history: Provides access to browser session history.
  • screen: Provides information about the display screen.

9. Window Object

The window object represents the browser window. It is the global object in a browser's JavaScript environment.

Common Window Methods

  • alert(): Displays an alert message.
  • confirm(): Displays a confirmation dialog.
  • prompt(): Displays a dialog asking for user input.
  • setTimeout(): Executes a function after a delay.
  • setInterval(): Repeatedly executes a function at intervals.
  • open(): Opens a new browser window or tab, subject to browser rules.

Example

window.alert("Welcome to JavaScript!");

let answer = window.confirm("Are you sure?");

let name = window.prompt("Enter your name");

10. Navigator Object

The navigator object provides information about the browser environment and its capabilities.

Example

console.log(navigator.userAgent);

console.log(navigator.language);

console.log(navigator.onLine);

11. Location Object

The location object contains information about the current URL and can be used for navigation.

Common Properties and Methods

  • href: Returns or sets the complete URL.
  • hostname: Returns the hostname.
  • pathname: Returns the path of the URL.
  • protocol: Returns the URL protocol.
  • reload(): Reloads the current page.
  • assign(): Loads a new URL.

Example

console.log(location.href);

console.log(location.hostname);

console.log(location.pathname);

12. History Object

The history object provides access to the browser's session history.

Common Methods

  • back(): Moves to the previous page in history.
  • forward(): Moves to the next page in history.
  • go(): Moves to a specific position in history.

Example

history.back();

history.forward();

history.go(-1);

13. Screen Object

The screen object provides information about the user's display screen.

Common Properties

  • width: Returns the screen width.
  • height: Returns the screen height.
  • availWidth: Returns the available screen width.
  • availHeight: Returns the available screen height.
  • colorDepth: Returns the screen color depth.

Example

console.log(screen.width);

console.log(screen.height);

console.log(screen.colorDepth);

14. Difference Between DOM and BOM

DOM BOM
Document Object Model. Browser Object Model.
Represents the webpage document. Represents the browser environment.
Used to manipulate HTML and XML content. Used to interact with browser features.
Uses objects such as document and elements. Uses objects such as window, location and history.
Example: document.getElementById(). Example: window.alert().

15. Practical Example: DOM Manipulation

This example demonstrates how JavaScript uses the DOM to change the content of a webpage. 

<!DOCTYPE html>
<html>
<head>
    <title>DOM Example</title>
</head>
<body>

    <h2 id="heading">Welcome to Web Technology</h2>

    <button onclick="changeText()">
        Change Text
    </button>

    <script>
        function changeText() {
            document.getElementById("heading")
                .textContent = "DOM Manipulation Successful!";
        }
    </script>

</body>
</html>

16. Advantages of Object Models

  • Provide structured access to webpage elements.
  • Allow dynamic modification of document content.
  • Support interactive web applications.
  • Make event handling easier.
  • Help JavaScript interact with browser features.
  • Support reusable and organized programming.
