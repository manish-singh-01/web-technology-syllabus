Using XML Processors: DOM and SAX

Unit 2 | Topic 11

Learn how XML documents are parsed and processed using DOM and SAX parsers.

1. Introduction to XML Processors

XML processors are software components that read, parse and process XML documents. They help applications access, validate and manipulate XML data.

XML processors check the structure of an XML document and make its data available to applications.

Important Points

  • XML processors read XML documents.
  • They identify elements, attributes and text.
  • They help applications access XML data.
  • They can check XML document structure.
  • DOM and SAX are two common XML parsing approaches.

2. What is XML Parsing?

XML parsing is the process of reading an XML document and analyzing its structure and content. A parser converts XML data into a form that an application can understand and process.

Example XML Document

<?xml version="1.0"?>

<student>
    <name>Rahul</name>
    <rollno>101</rollno>
    <course>B.Tech CSE</course>
</student>

An XML parser reads this document and identifies the student element, its child elements and their values.

3. Types of XML Parsers

1. DOM Parser

DOM stands for Document Object Model. A DOM parser reads the complete XML document and creates an in-memory tree structure.

2. SAX Parser

SAX stands for Simple API for XML. A SAX parser reads an XML document sequentially and generates events when it encounters elements, text and other document components.

4. DOM Parser

DOM is a tree-based XML parsing approach. It loads the XML document into memory and represents it as a hierarchical tree of nodes.

Working of DOM Parser

  1. Reads the XML document.
  2. Loads the complete document into memory.
  3. Creates a tree structure of nodes.
  4. Allows applications to access any node.
  5. Allows nodes to be added, modified or deleted.

DOM Tree Example

              Document
                  |
               Student
              /   |    \
           Name Rollno Course
            |     |      |
          Rahul  101   B.Tech

Features of DOM Parser

  • Loads the complete XML document into memory.
  • Provides random access to document nodes.
  • Supports modification of XML content.
  • Represents XML data in tree form.
  • Suitable for smaller and medium-sized documents.

5. DOM Parser Example Using JavaScript

JavaScript provides DOMParser to parse XML text and create a document object. 

let xmlData = `
<student>
    <name>Rahul</name>
    <rollno>101</rollno>
</student>
`;

let parser = new DOMParser();

let xmlDoc = parser.parseFromString(
    xmlData,
    "text/xml"
);

let name = xmlDoc
    .getElementsByTagName("name")[0]
    .textContent;

console.log(name);

Output: 

Rahul

6. Advantages of DOM Parser

  • Provides easy access to all document nodes.
  • Allows random access to XML elements.
  • Supports adding, updating and deleting nodes.
  • Provides a clear tree-based representation.
  • Useful when multiple parts of XML data need to be accessed.

Disadvantages of DOM Parser

  • Loads the entire document into memory.
  • Requires more memory for large XML files.
  • May be slower for very large documents.

7. SAX Parser

SAX stands for Simple API for XML. It is an event-based XML parsing approach.

Unlike DOM, SAX does not normally load the entire XML document into memory. It reads the document sequentially and generates events when different XML components are encountered.

Working of SAX Parser

  1. Reads the XML document from beginning to end.
  2. Identifies XML elements and attributes.
  3. Generates events for document components.
  4. Calls the appropriate event-handling methods.
  5. Continues reading until the end of the document.

Important SAX Events

  • startDocument(): Called when document parsing starts.
  • endDocument(): Called when document parsing finishes.
  • startElement(): Called when a start tag is encountered.
  • endElement(): Called when an end tag is encountered.
  • characters(): Called when character data is encountered.

8. SAX Parser Example

The following is a simplified event sequence for parsing an XML document.

XML Document

<student>
    <name>Rahul</name>
    <rollno>101</rollno>
</student>

Illustrative SAX Event Output

startDocument()

startElement: student

startElement: name
characters: Rahul
endElement: name

startElement: rollno
characters: 101
endElement: rollno

endElement: student

endDocument()

This sequence shows how a SAX parser processes XML data from beginning to end and generates events for each component.

9. Advantages of SAX Parser

  • Uses less memory compared to DOM.
  • Suitable for large XML documents.
  • Processes data sequentially.
  • Can begin processing before the entire document is read.
  • Useful for event-based applications.

Disadvantages of SAX Parser

  • Does not provide direct random access to nodes.
  • Does not automatically create a complete document tree.
  • Changing XML data is more difficult.
  • Applications must handle parsing events.
  • Previously processed content may need to be stored separately if required again.

10. Difference Between DOM and SAX

DOM Parser SAX Parser
Tree-based parser. Event-based parser.
Loads the complete document into memory. Reads the document sequentially.
Requires more memory for large documents. Generally requires less memory.
Supports random access to nodes. Does not provide direct random access.
Allows easy modification of the document tree. Does not directly provide document tree modification.
Suitable for smaller documents and complex navigation. Suitable for large documents and sequential processing.
Works with a tree of nodes. Works with parsing events.

11. Applications of DOM and SAX

Applications of DOM

  • Editing XML documents.
  • Accessing specific XML elements.
  • Modifying document structure.
  • Displaying structured data in applications.

Applications of SAX

  • Processing large XML files.
  • Reading XML data streams.
  • Extracting selected information from XML.
  • Processing data with limited memory.

12. How to Choose Between DOM and SAX?

Choose DOM When:

  • You need to access different nodes repeatedly.
  • You want to modify XML document content.
  • You need a complete tree representation.

Choose SAX When:

  • You need to process a large XML document.
  • You want sequential reading of data.
  • You want to reduce memory usage.
  • You only need to extract selected information.
