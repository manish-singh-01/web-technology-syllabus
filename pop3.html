TOPIC 06

POP3

POP3 stands for Post Office Protocol Version 3. It is an application-layer protocol that allows an email client to retrieve messages from a mail server.

01 • INTRODUCTION

What is POP3?

POP3 is used to download email messages from a mail server to a user's email application. Traditionally, downloaded messages may be removed from the server, depending on the client's settings.

POP3 is mainly designed for retrieving emails. SMTP, in contrast, is primarily used for sending them.

02 • WORKING

How POP3 Works

Mail Server→ POP3 Client→ Downloaded Emails
  • The email client connects to the mail server.
  • The user is authenticated.
  • The client checks the available messages.
  • Messages are downloaded to the client.
  • The connection is closed after retrieval.

03 • PORT NUMBERS

POP3 Ports

  • Port 110: Standard POP3 port without built-in TLS encryption.
  • Port 995: Commonly used for POP3 over implicit TLS.

Secure email access should use the security configuration supported by the mail provider.

04 • ADVANTAGES

Advantages of POP3

  • Emails can be downloaded for offline access.
  • Local storage can reduce dependence on continuous server access.
  • It is supported by many email clients.

Limitations of POP3

  • It is less suitable for synchronizing email across multiple devices.
  • Messages stored only on one device may be difficult to access elsewhere.
  • Server copies depend on client settings and provider configuration.

05 • POP3 VS IMAP

Difference Between POP3 and IMAP

  • POP3: Commonly downloads messages to a client for local access.
  • IMAP: Keeps messages on the server and synchronizes mailbox state across devices.
  • POP3: Useful when simple email downloading is sufficient.
  • IMAP: Generally more convenient when using several devices.

06 • EXAM PREPARATION

Important Questions with Answers

1. What is POP3?

POP3 stands for Post Office Protocol Version 3. It is an application-layer protocol used by email clients to retrieve messages from a mail server.

2. Which ports does POP3 use?

POP3 commonly uses port 110 for standard connections and port 995 for connections using implicit TLS.

3. What is the main limitation of POP3?

POP3 is less suited to synchronizing the same mailbox across multiple devices, especially when messages are downloaded locally.

4. Differentiate SMTP and POP3.

SMTP is primarily used to send emails, whereas POP3 is used to retrieve or download emails from a mail server.
